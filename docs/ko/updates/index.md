# 새로운 기능

이 페이지에서는 현재 설명서에 반영된 주요 작업 흐름 변경 사항을 요약합니다. 스토어의 출시 노트를 대신하지는 않습니다.

## Annotium 4.x

- 저장한 작업을 위한 프로젝트 갤러리가 추가되었습니다.
- 나중에 주석을 선택하고 수정할 수 있도록 편집 가능한 프로젝트 저장 기능이 추가되었습니다.
- 맥락을 보충할 프로젝트 메모 기능이 추가되었습니다.
- 문서 형태로 전달할 수 있는 PDF 내보내기 기능이 추가되었습니다.
- 선택 사항인 사진/갤러리에 자동 저장 (Auto save to photo/gallery) 작업 흐름이 추가되었습니다.
- 여러 이미지를 결합하는 사진 이어 붙이기 기능이 추가되었습니다.
- 각도 및 선 도구가 개선되었습니다.
- 화살표, 하이라이트 및 기타 개체의 선택과 편집 기능이 개선되었습니다.
- 도형, 텍스트, 말풍선, 자유 그리기, 자르기, 돋보기, 스포트라이트, 개인 정보 보호 효과, 아이콘 및 측정 도구를 계속 지원합니다.

## 이전 설명서에서 다룬 내용

이전 설명서는 기기 사진 탐색, 앨범 전환, 삭제할 사진 선택, 그리기 화면 열기, 그리기 메뉴 및 속성 메뉴 선택에 중점을 두었습니다. 해당 내용은 [프로젝트 및 사진](/ko/guide/workspaces),
[편집기 개요](/ko/guide/editor-overview), [도구 개요](/ko/tools/overview)에 유지하고 재구성했습니다.
