# 메모

프로젝트 메모는 프리미엄 기능입니다. 이미지가 복잡해지지 않도록 관찰 사항, 식별 정보, 후속 작업 또는 공동 작업자를 위한 간단한 설명을 메모에 기록하세요.

## 메모 열기 및 편집하기

- 편집기에서 메모 시트를 여세요.
- 서식 있는 텍스트 (Rich Text) 모드로 작성하세요.
- 마크다운 소스 (Markdown Source) 모드로 전환하세요.
- 시트를 닫고 메모가 프로젝트에 어떻게 저장되는지 확인하세요.

## 유용한 메모 작성하기

- 주석을 만든 이유를 기록하세요.
- 사진에 보이지 않는 세부 정보를 적어 두세요.
- 후속 작업이나 상태를 기록하세요.
- 저장 및 공유 방식이 적절하지 않다면 메모에 비밀 정보를 넣지 마세요.

## 유용한 맥락 삽입하기

- 날짜와 시간을 삽입하세요.
- 권한을 허용한 후 위치를 삽입하세요.
- 알아보기 쉬운 제목으로 링크를 추가하세요.

## 메모와 텍스트 주석 비교

단어가 내보낸 이미지에 함께 표시되어야 한다면 텍스트 주석을 사용하세요. 편집 가능한 작업과 함께 보관해야 할 배경 정보는 프로젝트 메모에 기록하세요.

## 공유하기 전에

프로젝트를 PDF로 내보낼 때 네 가지 레이아웃 중 하나를 선택하세요.

- **이미지 위, 텍스트 아래 (Image Above, Text Below)**는 이미지를 위쪽 절반에, 메모를 아래에 배치합니다.
- **텍스트 위, 이미지 아래 (Text Above, Image Below)**는 순서를 반대로 배치합니다.
- **텍스트 왼쪽, 이미지 오른쪽 (Text Left, Image Right)**은 메모를 왼쪽에, 이미지를 오른쪽에 배치합니다.
- **이미지 왼쪽, 텍스트 오른쪽 (Image Left, Text Right)**은 좌우 배치 순서를 반대로 합니다.

메모는 서식이 적용된 텍스트로 렌더링됩니다. 공유하기 전에 PDF를 검토해 선택한 레이아웃에서 메모와 이미지가 잘 읽히는지 확인하세요.
