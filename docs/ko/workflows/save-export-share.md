# 저장, 내보내기 및 공유

## 출력 형식 이해하기

| 출력 | 적합한 용도 | 나중에 편집할 수 있나요? |
| --- | --- | --- |
| 프로젝트 | Annotium에서 작업 이어 하기 | 예, 해당 접근 권한이 있는 경우 |
| JPEG 또는 PNG | 메시지, 보고서, 업로드 | 아니요, 이미지가 합쳐집니다 |
| PDF | 문서, 인쇄, 프로젝트 메모 | 아니요, 전달용 형식입니다 |

## 프로젝트에서 저장하기

- 프로젝트 데이터는 저장되며 편집 가능한 상태로 유지됩니다.
- 갤러리에 이미지도 함께 저장하려면 선택 사항인 **자동 저장 (Auto save)** 설정을 사용하세요.

## 내보내기 및 공유하기

- JPEG로 내보내세요.
- PNG로 내보내세요.
- 프로젝트를 PDF로 내보내고 템플릿을 선택하세요(프리미엄).
- 폴더를 PDF로 내보내세요(프리미엄).
- 운영체제의 공유 시트를 사용하세요.
