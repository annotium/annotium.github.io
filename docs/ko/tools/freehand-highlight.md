## 펜과 손가락 조작 개선하기

- 스타일러스, 중간 크기의 손가락 터치 영역 또는 큰 손가락 터치 영역에 맞게 터치 포인트 영역 (Touch Point Area)을 설정하세요.
- 손가락을 따라다니는 돋보기를 켜거나 끄세요.
- 세밀하게 그리기 전에 확대하세요.
- 정확하지 않은 선은 실행 취소하고 다시 그리세요.
