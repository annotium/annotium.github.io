# 선 측정

아래 차고 문 너비처럼 대상 부분을 가로질러 길이를 표시하세요.

<img src="/images/tools/line-measure/line-measure-result.webp" alt="빨간색 양방향 선 측정이 차고 문 위를 가로지르며 중앙 안내문 위에 있고, 샘플 라벨 2.40 m가 표시되어 있습니다." style="width:100%;height:auto;border-radius:12px;" />

1. 선 도구에서 **선 측정 (Line Measure)**을 선택하세요.
2. 측정할 길이의 한쪽 끝에서 다른 쪽 끝까지 드래그하세요.
3. 짧은 라벨을 입력하고 필요한 경우 텍스트 위치를 조정하세요.

`2.40 m` 라벨은 샘플 텍스트이며 이 사진에서 측정한 값이 아닙니다. 실제 길이로 사용하기 전에 축척을 설정하고 확인하세요. **선 측정에는 프리미엄이 필요합니다.**
