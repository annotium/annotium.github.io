# 돋보기 (Loupe)

원래 위치를 가리지 않고 세부 항목을 확대해 보여 주세요.

<img src="/images/tools/loupe/loupe-result.webp" alt="원형 돋보기가 배관 연결부를 확대하고, 포인터는 싱크대 수리 사진에서 원본 위치를 표시합니다." style="width:100%;height:auto;border-radius:12px;" />

1. **초점 도구 (focus tools)**에서 **돋보기**를 선택하세요.
2. 렌즈를 놓을 위치에 그리세요.
3. 원본 지점을 세부 항목으로 옮기고 렌즈를 조정하세요.

돋보기는 이미지 일부를 확대합니다. 캔버스를 확대하거나 이동하지는 않습니다.
