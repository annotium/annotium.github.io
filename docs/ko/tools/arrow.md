# 화살표

빈 공간에서 세부 항목 쪽으로 드래그하세요. 화살촉은 드래그를 끝낸 지점에 놓입니다.

<img src="/images/tools/arrow/arrow-result.webp" alt="긴 빨간색 화살표가 노출된 벽면 콘센트를 가리키고, 원형 돋보기가 대상을 확대합니다." style="width:100%;height:auto;border-radius:12px;" />

1. 사진을 열고 선 도구에서 **화살표 (Arrow)**를 선택하세요.
2. 시작 지점에서 세부 항목까지 드래그하세요.
3. 화살표를 선택해 색상, 굵기 또는 끝 모양을 변경하세요.

<figure>
  <img src="/images/tools/arrow/arrow-tool-picker.webp" alt="Annotium 도구 선택기가 콘센트와 플러그 사진 위에 열려 있고, 화살표 도구가 청록색으로 강조되어 있습니다." style="width:100%;height:auto;border-radius:12px;" />
  <figcaption>1단계: 도구 선택기를 열고 선 도구에서 청록색 화살표 아이콘을 선택하세요.</figcaption>
</figure>

<figure>
  <img src="/images/tools/arrow/arrow-drag-step.webp" alt="선택된 빨간색 화살표가 플러그에서 벽면 콘센트 쪽으로 이어지고, 원형 돋보기가 콘센트 위에 있습니다." style="width:100%;height:auto;border-radius:12px;" />
  <figcaption>2단계: 플러그에서 콘센트 쪽으로 드래그하세요. 화살표가 선택되어 있으며 기존 돋보기가 대상 위에 표시됩니다.</figcaption>
</figure>

<figure>
  <img src="/images/tools/arrow/arrow-properties.webp" alt="선택된 빨간색 화살표의 속성에 채우기, 선, 경로 탭과 불투명도, 색상 선택 항목 및 잠금 해제된 스타일 조절 옵션이 표시되어 있습니다." style="width:100%;height:auto;border-radius:12px;" />
  <figcaption>3단계: 속성을 열어 선택한 화살표의 모양을 변경하세요.</figcaption>
</figure>

위 화살표는 한 번의 연속된 드래그로 그렸습니다. 프로젝트에서는 주석을 편집 가능한 상태로 유지하고, 사진에서는 기기 사진 보관함을 사용합니다.
