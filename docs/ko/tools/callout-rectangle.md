# 말풍선(사각형) (Callout (Rectangle))

세부 항목에 설명이 필요할 때 짧은 라벨을 사용하세요.

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="빨간색 윤곽선의 흰색 말풍선에 ‘간격 확인’이라고 적혀 있고, 닫힌 차고 문에 붙은 작은 노란색 안내문을 정확히 가리킵니다." style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="‘파이프 점검’이라고 적힌 흰색 둥근 사각형 말풍선이 배수관을 가리킵니다. 다른 파이프에는 반투명한 빨간색 하이라이트가 남아 있습니다." style="width:100%;height:auto;border-radius:12px;" />

1. **텍스트 도구 (Text tools)**에서 **말풍선(사각형) (Callout (Rectangle))**을 선택하세요.
2. 드래그해 상자 크기를 정하고 포인터를 세부 항목 가까이에 놓으세요.
3. 짧은 메모를 입력한 다음 사진을 가리면 상자를 옮기세요.
4. **속성 (Properties)**을 열어 텍스트 크기, 글꼴 또는 색상을 조정하세요.
5. **선 (Stroke)**에서 말풍선 윤곽선의 색상과 굵기를 선택하세요.
6. **채우기 (Fill)**에서 배경색을 선택하고 불투명도를 설정하세요.
