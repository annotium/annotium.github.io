# 치수선

길이를 표시한 다음 측정 눈금을 띄워 대상이 잘 보이게 하세요. **치수선에는 프리미엄이 필요합니다.**

<img src="/images/tools/dimension-line/dimension-line-result.jpg" alt="청록색 작업 표면 위의 금속 부품에 기존 흰색 및 노란색 치수가 표시되어 있습니다." style="width:100%;height:auto;border-radius:12px;" />

1. 선 도구에서 **치수선 (Dimension Line)**을 선택하세요.
2. 파이프 구간의 양 끝 사이를 드래그하세요.
3. 눈금 핸들을 위로 드래그하고 짧은 라벨을 입력하세요.

이 참고 이미지에는 이미 치수 주석이 포함되어 있습니다. 라벨은 제공된 이미지의 일부이며 Annotium 측정값이 아닙니다.
