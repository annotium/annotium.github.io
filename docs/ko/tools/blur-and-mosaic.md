# 흐림 및 모자이크 (Blur and Mosaic)

영역을 부드럽게 처리하려면 **흐림 (Blur)**을, 블록으로 바꾸려면 **모자이크 (Mosaic)**를 사용하세요.

## 흐림

<img src="/images/tools/blur/blur-result.webp" alt="Annotium의 흐림 도구가 샘플 송장의 선택 영역에 있는 손글씨 세부 정보를 흐리게 처리합니다." style="width:100%;height:auto;border-radius:12px;" />

## 모자이크

<img src="/images/tools/mosaic/mosaic-result.webp" alt="사각형 모자이크 효과가 차고 문 안내문의 일부를 가립니다." style="width:100%;height:auto;border-radius:12px;" />

1. **개인정보 보호 도구 (privacy tools)**에서 **흐림 (Blur)** 또는 **모자이크 (Mosaic)**를 선택하세요.
2. 숨기려는 세부 항목 위로 드래그하세요.
3. 영역 크기를 조정하고 공유하기 전에 전체 크기 결과를 확인하세요.

흐림 예시에는 개인 정보가 제거된 CC0 샘플 송장을 사용했습니다. 모자이크 예시에는 공개된 차고 사진을 사용했습니다. 비공개 자료라면 내보낸 사본에서 해당 세부 정보를 읽을 수 없는지 확인하세요.
