## 화살표 색 변경

1. **이동 (Pan)**을 탭하고 캔버스에서 화살표를 선택하세요.
2. **속성 (Properties)**을 열고 **선 (Stroke)**을 선택하세요.
3. 색을 탭하세요. 선택한 화살표의 색이 캔버스에서 바뀝니다.

<img src="/images/tools/arrow/arrow-properties.webp" alt="선택한 화살표의 속성에 채우기, 선, 경로 탭과 색상 팔레트가 표시되어 있습니다." width="360" />

다음 주석의 스타일을 설정하려면 선택을 해제하고 그리기 도구를 선택한 다음 그리기 전에 속성을 설정하세요.

## 필요한 속성 선택

| 변경할 항목 | 찾을 위치 |
| --- | --- |
| **윤곽선 (Outline)** 색상, **불투명도 (Opacity)**, **굵기 (Width)** 또는 **선 (Dash)** 패턴 | **선 (Stroke)** |
| 닫힌 도형이나 말풍선 내부의 색상 또는 불투명도 | **채우기 (Fill)** |
| 선택한 도구의 화살표 끝 또는 도형 옵션 | **경로 (Path)** |
| **글꼴 (Font)**, **크기 (Size)**, **정렬 (Align)** 또는 **텍스트 색상 (Text Color)** | 선택한 텍스트 주석의 텍스트 설정 |

사용 가능한 제어 항목은 선택한 도구에 따라 다릅니다. 일부 스타일 제어 항목에는 프리미엄이 필요합니다.
