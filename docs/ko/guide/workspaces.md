# 프로젝트와 사진

홈 화면 왼쪽 상단의 작업 공간 전환기를 탭해 **프로젝트 (Projects)** 또는 **사진 (Photos)**을 선택하세요. 전환하면 제목과 그리드가 바뀝니다.

<img src="/images/getting-started/switching.jpg" alt="작업 공간 전환기에서 프로젝트와 사진을 선택할 수 있습니다." width="360" />

| 작업 공간 | 선택할 때 | 저장 결과 |
| --- | --- | --- |
| **프로젝트** | 폴더, 프로젝트 메모 또는 개별 주석을 다시 살펴볼 기능이 필요한 경우. | 편집 가능한 프로젝트입니다. 기존 주석을 유지한 채 다시 열려면 프리미엄이 필요합니다. |
| **사진** | 기기 앨범의 사진에 주석을 추가하려는 경우. | 주석이 이미지에 포함된 단일 이미지입니다. 기본 저장 위치는 기기의 사진 보관함입니다. |
