# Perguntas frequentes

## Por que não consigo selecionar uma anotação em uma foto exportada?

As exportações de fotos e PDFs são arquivos finais achatados. Abra o projeto salvo do Annotium para editar objetos individuais.

## Onde foi parar minha imagem salva?

Confira o app Fotos ou Galeria do dispositivo e confirme se o Annotium tem permissão para adicionar imagens. Se o **Salvamento automático (Auto save)** estiver desativado, use a ação de salvar ou compartilhar.

## Por que vejo imagens duplicadas?

O Salvamento automático pode estar ativado enquanto você também salva manualmente. Desative o salvamento automático ou use sempre o mesmo método para concluir.

## Posso revisar um projeto antigo?

Quem tem Premium pode reabrir o documento salvo e revisar seus objetos. Sem
Premium, o Annotium pode criar uma nova cópia achatada e manter o projeto
original intacto.

## Devo usar uma nota ou uma caixa de texto?

Use uma nota para o contexto do projeto; use uma caixa de texto quando as palavras precisarem aparecer na imagem exportada.

## Os valores de ângulo e distância são exatos?

Eles dependem da posição dos pontos, da escala da imagem e da perspectiva. Considere-os anotações visuais, a menos que seu fluxo de trabalho esteja calibrado.

## Posso combinar várias capturas de tela?

Use [Imagens e composição](/pt-BR/tools/images-compose) para criar uma colagem ou
unir imagens vertical ou horizontalmente e, em seguida, anotar o resultado
combinado.
