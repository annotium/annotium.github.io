# Navegar pelas fotos do dispositivo

## Abrir uma foto

1. Mude para **Fotos (Photos)** na tela inicial.
2. Permita o acesso às fotos se o dispositivo solicitar. Se o acesso tiver sido negado, toque em **Abrir Configurações (Open Settings)** e revise as permissões de fotos do Annotium.
3. Toque no título do álbum para escolher um álbum e, em seguida, toque em uma foto para editá-la.

<img src="/images/photos/browse.png" alt="O espaço de trabalho Fotos mostra o título de um álbum acima de uma grade de miniaturas." width="360" />

Puxe a grade para baixo para atualizá-la. Para começar com uma foto nova, use o botão da câmera. Com Premium, abra **+ → Compor (Compose)** para [combinar várias fotos](/pt-BR/tools/images-compose#compose-photos).

## Salvar uma imagem anotada

Toque em **Voltar (Back)** e escolha **Salve (Save)** quando solicitado. Fotos salva uma imagem achatada, por padrão na biblioteca de fotos do dispositivo. Para manter as anotações editáveis depois, comece em [Projetos](/pt-BR/guide/projects).

## Apagar fotos

Toque e segure uma miniatura, toque em outras fotos para selecioná-las e escolha **Apagar (Delete)**; em seguida, revise a confirmação.

<img src="/images/photos/delete.png" alt="O espaço de trabalho Fotos mostra miniaturas selecionadas e os controles para gerenciar a seleção." width="360" />

::: danger Biblioteca de fotos do dispositivo
Apagar fotos aqui as remove da biblioteca do dispositivo. O recurso Desfazer do Annotium se aplica às ações do editor.
:::
