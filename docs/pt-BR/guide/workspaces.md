# Projetos e Fotos

Toque no seletor de espaço de trabalho, no canto superior esquerdo da tela inicial, para escolher **Projetos (Projects)** ou **Fotos (Photos)**. O título e a grade mudam quando você alterna entre eles.

<img src="/images/getting-started/switching.jpg" alt="O seletor de espaço de trabalho mostra Projetos e Fotos." width="360" />

| Espaço de trabalho | Escolha quando | Resultado salvo |
| --- | --- | --- |
| **Projetos** | Você quiser pastas, notas de projeto ou a possibilidade de revisar anotações individuais. | Um projeto editável. Para reabrir as anotações existentes e editá-las, é necessário ter Premium. |
| **Fotos** | Você quiser fazer anotações em uma foto de um álbum do dispositivo. | Uma imagem achatada com as anotações incorporadas. O destino padrão é a biblioteca de fotos do dispositivo. |
