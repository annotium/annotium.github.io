Os projetos são arquivos de trabalho para anotações que você pode retomar. Eles preservam a imagem base, os objetos de anotação compatíveis e o contexto do projeto.

## Criar um projeto

Abra ou tire uma foto, adicione anotações e saia do editor pelo fluxo de salvamento. O resultado aparece na grade de Projetos.

/>


## Reabrir e editar

- Com Premium, reabra o documento salvo e continue editando os objetos.
- Sem Premium, crie uma nova cópia achatada e mantenha o projeto original intacto, ou escolha desbloquear Premium.

<img
  src="/images/projects/items.png"
  alt="Lista de itens"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## Organizar projetos

- Crie pastas.
- Renomeie e mova projetos ou pastas.
- Duplique um ou mais projetos.
- Adicione uma nota ao projeto (Premium).
- Exporte uma pasta para PDF (Premium).

<img
  src="/images/projects/note.png"
  alt="Nota"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## Excluir com cuidado

Antes de excluir um projeto ou uma pasta, confirme se todos os arquivos necessários já foram exportados e salvos em backup. Uma imagem em **Fotos (Photos)** é achatada e não substitui o projeto editável.

::: tip Uma regra simples
Projeto = arquivo de trabalho. Foto ou PDF = cópia final.
:::
