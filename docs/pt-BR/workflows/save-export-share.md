# Salvar, exportar e compartilhar

## Entender os tipos de saída

| Saída | Ideal para | Editável depois? |
| --- | --- | --- |
| Projeto | Continuar o trabalho no Annotium | Sim, com o acesso aplicável |
| JPEG ou PNG | Mensagens, relatórios e envios | Não, achatado |
| PDF | Documentos, impressão e notas do projeto | Não, formato de entrega |

## Salvar em **Projetos (Projects)**

- Os dados do projeto são salvos e permanecem editáveis.
- A preferência opcional **Salvamento automático (Auto save)** também salva uma imagem na galeria.

## Salvar em **Fotos (Photos)**

Fotos salva uma imagem achatada, usando por padrão a biblioteca de fotos do dispositivo como destino.

## Exportar e compartilhar

- Exporte um JPEG.
- Exporte um PNG.
- Exporte um PDF do projeto e escolha um modelo (Premium).
- Exporte uma pasta como PDF (Premium).
- Use a folha de compartilhamento do sistema operacional.

Escolha **Qualidade da imagem (Image Quality)** e **Salvar formato de imagem (Save Image Format)** antes de exportar.
