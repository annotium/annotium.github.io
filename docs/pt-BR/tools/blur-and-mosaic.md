# Desfoque e mosaico

Use **Desfoque (Blur)** para suavizar uma área ou **Mosaico (Mosaic)** para substituí-la por blocos.

## Desfoque

<img src="/images/tools/blur/blur-result.webp" alt="A ferramenta Desfoque do Annotium suaviza detalhes manuscritos em uma área selecionada de uma fatura de amostra." style="width:100%;height:auto;border-radius:12px;" />

## Mosaico

<img src="/images/tools/mosaic/mosaic-result.webp" alt="Um efeito de mosaico retangular cobre parte de um aviso em uma porta de garagem." style="width:100%;height:auto;border-radius:12px;" />

1. Escolha **Desfoque** ou **Mosaico** em **Ferramentas de privacidade (privacy tools)**.
2. Arraste sobre o detalhe que você quer ocultar.
3. Redimensione a área e confira o resultado em tamanho real antes de compartilhar.

O exemplo de desfoque usa uma fatura de amostra CC0 com os dados pessoais removidos. O exemplo de mosaico usa uma foto pública de uma garagem. Para materiais privados, confira se o detalhe não pode ser lido na cópia exportada.
