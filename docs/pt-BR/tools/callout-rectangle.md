# Balão (retângulo) (Callout (Rectangle))

Use um rótulo breve quando o detalhe precisar de uma explicação.

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="Um balão branco contornado em vermelho com a frase Verifique a folga aponta diretamente para o pequeno aviso amarelo em uma porta de garagem fechada." style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="Um balão retangular branco com cantos arredondados e a frase Verifique o cano aponta para um tubo de drenagem; um destaque vermelho translúcido continua sobre outro cano." style="width:100%;height:auto;border-radius:12px;" />

1. Escolha **Balão (retângulo)** em **Ferramentas de texto (Text tools)**.
2. Arraste para definir o tamanho da caixa e coloque o ponteiro perto do detalhe.
3. Digite uma observação curta e mova a caixa se ela cobrir a foto.
4. Abra **Propriedades (Properties)** para ajustar o tamanho do texto, a fonte ou a cor.
5. Use **Contorno (Stroke)** para escolher a cor e a espessura do contorno do balão.
6. Use **Preenchimento (Fill)** para escolher uma cor de fundo e definir sua opacidade.
