## Estilize uma forma

- Ative ou desative o contorno e o preenchimento quando disponíveis.
- Defina a espessura, a cor e a opacidade do contorno.
- Escolha um preenchimento sólido ou com padrão.
- Redimensione e altere a forma usando as alças.

## Exemplos sugeridos

Use uma tarefa real para cada família de ferramentas: enquadre um defeito, circule um controle, contorne uma área irregular e marque uma peça anular.
