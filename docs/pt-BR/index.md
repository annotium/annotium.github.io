## Medidas sem promessas enganosas

O Annotium mede **ângulos** em uma foto. Para medir comprimentos, use uma trena ou um medidor no local; o Annotium desenha uma linha de cota nítida com o valor informado. Ele não calcula distâncias a partir de uma imagem.
