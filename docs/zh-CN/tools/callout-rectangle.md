# 标注(矩形)

需要解释某个细节时，可添加简短标签。

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="红色描边的白色标注写着“检查间隙”，指向一扇关闭的车库门上的黄色小告示。" style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="白色圆角矩形标注写着“检查管道”，指向一根排水管；另一根管道上仍有一条半透明红色高亮标记。" style="width:100%;height:auto;border-radius:12px;" />

1. 从文字工具中选择 **标注(矩形) (Callout (Rectangle))**。
2. 拖动以设置文本框大小，并将指示尖端放在细节附近。
3. 输入简短备注；如果文本框遮挡照片，可移动文本框。
4. 打开 **属性 (Properties)**，调整文字大小、字体或颜色。
5. 使用 **描边 (Stroke)** 选择标注的轮廓颜色和粗细。
6. 使用 **填充 (Fill)** 选择背景颜色并设置不透明度。
