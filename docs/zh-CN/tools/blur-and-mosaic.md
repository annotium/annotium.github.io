# 模糊和马赛克

使用 **模糊** 柔化区域，或使用 **马赛克** 将区域替换为像素块。

## 模糊

<img src="/images/tools/blur/blur-result.webp" alt="Annotium 的模糊工具柔化了示例发票选定区域中的手写细节。" style="width:100%;height:auto;border-radius:12px;" />

## 马赛克

<img src="/images/tools/mosaic/mosaic-result.webp" alt="矩形马赛克效果遮盖了车库门上告示的一部分。" style="width:100%;height:auto;border-radius:12px;" />

1. 从隐私工具中选择 **模糊** 或 **马赛克**。
2. 在要隐藏的细节上拖动。
3. 调整区域大小，并在分享前检查完整尺寸的效果。

模糊示例使用一张 CC0 示例发票，个人信息已移除。马赛克示例使用一张公开的车库照片。对于私人材料，请确认导出副本中的细节无法辨认。
