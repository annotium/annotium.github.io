# 箭头

从空白处向细节方向拖动。箭头尖端会落在拖动终点。

<img src="/images/tools/arrow/arrow-result.webp" alt="一支红色长箭头指向露出的墙壁插座，旁边的圆形放大镜将目标放大。" style="width:100%;height:auto;border-radius:12px;" />

1. 打开照片，然后从线条工具中选择 **箭头 (Arrow)**。
2. 从起点拖动到细节处。
3. 选择箭头以更改其颜色、粗细或末端样式。
