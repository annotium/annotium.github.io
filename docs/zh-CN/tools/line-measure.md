# 直线测量

直接沿着目标横跨标记一段距离，例如下方车库门的宽度。

<img src="/images/tools/line-measure/line-measure-result.webp" alt="红色双向直线测量横跨车库门，位于中央告示上方，并显示示例标签 2.40 m。" style="width:100%;height:auto;border-radius:12px;" />

1. 从线条工具中选择 **直线测量 (Line Measure)**。
2. 从跨度的一端拖动到另一端。
3. 输入简短标签，并按需调整文字位置。

`2.40 m` 是示例文字，并非从这张照片测得的数值。若要将测量结果用作实际尺寸，请先设置并核实比例尺。**直线测量需要高级版。**
