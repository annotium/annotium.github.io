# 尺寸线

先标记一段距离，再抬高测量线，让物体保持清晰可见。**尺寸线需要高级版。**

<img src="/images/tools/dimension-line/dimension-line-result.jpg" alt="青绿色工作台上的金属部件，带有已有的白色和黄色尺寸标注。" style="width:100%;height:auto;border-radius:12px;" />

1. 从线条工具中选择 **尺寸线 (Dimension Line)**。
2. 在管段的两端之间拖动。
3. 向上拖动测量线手柄，然后输入简短标签。

此参考图片中已有尺寸标注。标签属于提供的图片内容，并非 Annotium 测量结果。
