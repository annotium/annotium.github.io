# 放大镜

显示特写，同时保留其来源位置。

<img src="/images/tools/loupe/loupe-result.webp" alt="圆形放大镜放大了水槽维修照片中的管道连接处，同时用指示线标出原始位置。" style="width:100%;height:auto;border-radius:12px;" />

1. 从聚焦工具中选择 **放大镜 (Loupe)**。
2. 拖动以放置镜片。
3. 将取景点移到细节处，并调整镜片。

放大镜会放大图像的一部分，但不会缩放或移动画布。
