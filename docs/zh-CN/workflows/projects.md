项目是可供日后继续处理的工作文件。它们会保留底图、受支持的注释对象和项目背景信息。

## 创建项目

打开或拍摄一张照片，添加注释，然后通过保存流程退出编辑器。创建的项目会显示在项目网格中。

/>


## 重新打开并编辑

- 使用高级版可重新打开已保存的文档，并继续编辑其中的对象。
- 不使用高级版时，可创建扁平化副本，同时保留原项目；也可以选择解锁高级版。

<img
  src="/images/projects/items.png"
  alt="项目列表"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## 整理项目

- 创建文件夹。
- 重命名或移动项目和文件夹。
- 复制一个或多个项目。
- 添加项目笔记（高级版）。
- 将文件夹导出为 PDF（高级版）。

<img
  src="/images/projects/note.png"
  alt="笔记"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## 谨慎删除

删除项目或文件夹前，请确认所有需要交付的内容都已导出并备份。保存在“照片”中的图像是扁平化版本，无法替代可编辑项目。

::: tip 简单规则
项目 = 工作文件。照片或 PDF = 交付副本。
:::
