# 更新内容

本页概述当前指南所涵盖的主要工作流程变化，不可替代应用商店的版本说明。

## Annotium 4.x

- 新增已保存作品的项目图库。
- 新增可编辑的已保存项目，之后可以选择和修改注释。
- 新增用于补充背景信息的项目笔记。
- 新增面向文档交付的 PDF 导出。
- 新增可选的**自动保存到照片/图库 (Auto save to photo/gallery)**输出流程。
- 新增照片拼接功能，可组合多张图像。
- 改进角度和直线工具。
- 改进箭头、高亮和其他对象的选择与编辑功能。
- 继续支持形状、文字、标注框、自由绘制、裁剪、放大镜、聚光灯、隐私效果、图标和测量工具。

## 早期指南涵盖的内容

旧版文档主要介绍浏览设备照片、切换相册、选择要删除的照片、打开绘图屏幕，以及从绘图菜单和属性菜单中进行选择。这些内容已在[项目与照片](/zh-CN/guide/workspaces)、[编辑器概览](/zh-CN/guide/editor-overview)和[工具概览](/zh-CN/tools/overview)中保留并重新编排。
