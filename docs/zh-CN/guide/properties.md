## 更改箭头颜色

1. 点按 **平移 (Pan)**，然后选中画布上的箭头。
2. 打开 **属性 (Properties)** 并选择 **描边 (Stroke)**。
3. 点按一种颜色。画布上的箭头会随之更新。

<img src="/images/tools/arrow/arrow-properties.webp" alt="所选箭头的属性面板显示填充 (Fill)、描边 (Stroke) 和路径 (Path) 选项卡以及调色板。" width="360" />

要为下一个标注设置样式，请取消选择对象，选择绘图工具，并在绘制前设置其属性。

## 选择所需属性

| 要更改的内容 | 查找位置 |
| --- | --- |
| 轮廓颜色、不透明度、宽度或虚线样式 | **描边 (Stroke)** |
| 闭合形状或标注内部的颜色或不透明度 | **填充 (Fill)** |
| 所选工具的箭头端点或几何选项 | **路径 (Path)** |
| 字体、大小、对齐方式或文字颜色 | 选中文字标注后显示的文字设置 |

可用控件取决于所选工具。部分样式控件需要高级版。
