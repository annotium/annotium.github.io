# 入门指南

打开一张照片，用箭头指向一个细节，然后保存。

## 打开照片

1. 点按主屏幕左上角的工作区切换器。
2. 选择 **项目 (Projects)** 以保留可编辑项目，或选择 **照片 (Photos)** 以使用设备照片图库中的照片。
3. 在**项目**中，点按 **+**，然后选择 **图库 (Gallery)**；也可以使用相机按钮。在**照片**中，点按一张缩略图。

<img src="/images/getting-started/switching.jpg" alt="主屏幕工作区切换器提供项目和照片选项。" width="360" />

## 绘制第一个箭头

1. 打开工具选择器，然后在线条工具中选择 **箭头 (Arrow)**。
2. 从空白处向细节拖动。松开手指的位置就是箭头尖端。
3. 如需更改箭头颜色，请先选中箭头，打开 **属性 (Properties)**，然后在 **描边 (Stroke)** 下选择颜色。

<img src="/images/tools/arrow/arrow-drag-step.webp" alt="箭头从电源插头指向墙上插座，两端都显示控制点。" width="360" />

## 保存工作

点按编辑器中的 **返回 (Back)**，并在提示时选择 **保存 (Save)**。已保存的工作会保留在**项目**网格中。**照片**会保存带标注的扁平化图片，通常保存到设备照片图库。要从编辑器发送副本，请使用 **导出 (Export)**。
