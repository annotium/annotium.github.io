# 项目和照片

点按主屏幕左上角的工作区切换器，选择**项目 (Projects)** 或**照片 (Photos)**。切换后，标题和网格也会改变。

<img src="/images/getting-started/switching.jpg" alt="工作区切换器显示项目和照片选项。" width="360" />

| 工作区 | 适用情况 | 保存结果 |
| --- | --- | --- |
| **项目 (Projects)** | 你需要文件夹、项目笔记，或希望之后重新查看各个标注。 | 可编辑项目。重新打开其中现有标注需要高级版。 |
| **照片 (Photos)** | 你想标注设备相册中的照片。 | 标注已合并到图片中的扁平化图像。默认保存到设备照片图库。 |
