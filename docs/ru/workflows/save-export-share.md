# Сохранение, экспорт и отправка

## Типы выходных файлов

| Тип | Для чего подходит | Можно редактировать позже? |
| --- | --- | --- |
| Проект | Продолжение работы в Annotium | Да, при наличии соответствующего доступа |
| JPEG или PNG | Отправка в сообщениях, отчёты и загрузка | Нет, изображение сведено в один слой |
| PDF | Документы, печать и заметки проекта | Нет, формат для передачи |

## Сохранение из раздела «Проекты»

- Данные проекта сохраняются, и его можно редактировать.
- При желании включите настройку **Автосохранение (Auto save)**, чтобы также сохранять изображение в галерее.

## Сохранение из раздела «Фото»

В разделе **Фото (Photos)** сохраняется сведённое изображение; по умолчанию оно помещается в фототеку устройства.

## Экспорт и отправка

- Экспортируйте файл JPEG.
- Экспортируйте файл PNG.
- Экспортируйте проект в PDF и выберите шаблон (Premium).
- Экспортируйте папку в PDF (Premium).
- Используйте системное меню отправки.

## Качество и формат

Перед экспортом выберите **Качество изображения (Image Quality)** и **Сохранить формат изображения (Save Image Format)**.
