# Выноска (прямоугольник) (Callout (Rectangle))

Добавьте короткую подпись, чтобы пояснить деталь.

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="Белая выноска с красным контуром и надписью «Проверьте зазор» указывает прямо на небольшую жёлтую табличку на закрытых гаражных воротах." style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="Белая скруглённая прямоугольная выноска с надписью «Проверьте трубу» указывает на сливную трубу; другая труба покрыта полупрозрачным красным выделением." style="width:100%;height:auto;border-radius:12px;" />

1. Выберите **Выноска (прямоугольник)** среди текстовых инструментов.
2. Перетащите, чтобы задать размер поля и расположить указатель рядом с деталью.
3. Введите короткую заметку, затем переместите поле, если оно закрывает фото.
4. Откройте **Свойства (Properties)**, чтобы изменить размер текста, шрифт или цвет.
5. В разделе **Обводка (Stroke)** выберите цвет и ширину контура выноски.
6. В разделе **Заливка (Fill)** выберите цвет фона и задайте его непрозрачность.
