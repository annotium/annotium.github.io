# Размерная линия (Dimension Line)

Отметьте длину, затем поднимите размерную линию, чтобы объект оставался виден. **Для размерной линии требуется Премиум.**

<img src="/images/tools/dimension-line/dimension-line-result.jpg" alt="Металлическая деталь на бирюзовой рабочей поверхности с существующими белыми и жёлтыми размерными обозначениями." style="width:100%;height:auto;border-radius:12px;" />

1. Выберите **Размерная линия** среди инструментов линий.
2. Проведите между двумя концами участка трубы.
3. Перетащите маркер размерной линии вверх и введите короткую подпись.

На этом исходном изображении уже есть размерные обозначения. Их подписи являются частью изображения и не представляют собой измерения Annotium.
