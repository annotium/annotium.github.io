## Создание проекта

<img src="/images/getting-started/projects.png" alt="В рабочем пространстве «Проекты» показаны сетка проектов и элементы управления для начала новой работы." width="360" />

1. Откройте **Проекты (Projects)**.
2. Нажмите **+**, выберите **Галерея (Gallery)** и укажите фото. Также можно нажать кнопку камеры.
3. Добавьте аннотации в редакторе. Используйте инструмент [Обрезать (Crop)](/ru/tools/images-compose#crop), если хотите кадрировать фото.
4. Нажмите **Назад (Back)** и при появлении запроса выберите **Сохранить (Save)**. Сохранённый проект появится в сетке.

С Премиум выберите **Составить (Compose)**, чтобы [объединить несколько фото](/ru/tools/images-compose#compose-photos) перед разметкой.

## Организация проектов

- Выберите **+ → Новая папка (New Folder)**, чтобы создать папку. Коснитесь папки, чтобы открыть её.
- Нажмите и удерживайте проект, чтобы перейти к выбору. Коснитесь других элементов, чтобы выбрать их, затем используйте доступные действия для перемещения или удаления.
- Откройте меню действий отдельного элемента, чтобы переименовать его. Дублируйте проект, если нужна отдельная версия.
- Перед удалением папки проверьте, какие проекты в ней находятся.

## Повторное открытие проекта

Коснитесь миниатюры проекта. С **Премиум (Premium)** исходный проект открывается так, что аннотации остаются редактируемыми. В бесплатной версии выберите **Редактировать копию (Edit copy)**, чтобы создать отдельный проект, в котором существующие аннотации объединены с фоном.

С Премиум откройте меню действий папки и выберите **Экспорт PDF (Export PDF)**, чтобы объединить проекты из неё в один PDF.
