プロジェクトは、後から見直す注釈の作業ファイルです。ベース画像、対応する注釈オブジェクト、プロジェクトの関連情報が保存されます。

## プロジェクトを作成する

写真を開くか撮影し、注釈を追加してから、保存操作でエディターを終了します。作成した項目はプロジェクトのグリッドに表示されます。

<img
  src="/images/projects/create.png"
  alt="新しいプロジェクトを作成"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## 再度開いて編集する

- プレミアムの場合は、保存したドキュメントを再度開き、オブジェクトの編集を続けられます。
- プレミアムでない場合は、元のプロジェクトをそのまま残して統合済みのコピーを新規作成するか、プレミアムのロック解除を選択します。

<img
  src="/images/projects/items.png"
  alt="項目の一覧"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## プロジェクトを整理する

- フォルダを作成します。
- プロジェクトやフォルダの名前を変更したり、移動したりします。
- 1つ以上のプロジェクトを複製します。
- プロジェクトのメモを追加します（プレミアム）。
- フォルダをPDFに書き出します（プレミアム）。

<img
  src="/images/projects/note.png"
  alt="メモ"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## 削除は慎重に

プロジェクトやフォルダを削除する前に、必要な成果物を書き出してバックアップしたことを確認してください。「写真」にある画像は統合済みで、編集可能なプロジェクトの代わりにはなりません。

::: tip 簡単な目安
プロジェクト = 作業ファイル。写真またはPDF = 提出用コピー。
:::
