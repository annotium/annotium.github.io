# 保存、書き出し、共有

## 出力形式を確認する

| 出力 | 用途 | 後から編集可能か |
| --- | --- | --- |
| プロジェクト | Annotiumで作業を続ける | はい。適用されるアクセス権が必要です |
| JPEGまたはPNG | メッセージ、レポート、アップロード | いいえ。統合済みです |
| PDF | ドキュメント、印刷、プロジェクトのメモ | いいえ。提出用の形式です |

## プロジェクトから保存する

- プロジェクトデータは保存され、編集可能な状態で残ります。
- 画像もギャラリーに保存する場合は、「自動保存 (Auto save)」の設定を任意で有効にします。

## 写真 (Photos) から保存する

「写真」から保存すると、統合済みの画像が保存されます。デフォルトの保存先は端末のフォトライブラリです。

## 書き出して共有する

- JPEGを書き出します。
- PNGを書き出します。
- プロジェクトをPDFに書き出し、テンプレートを選択します（プレミアム）。
- フォルダをPDFに書き出します（プレミアム）。
- OSの共有シートを使います。

## 画質と形式

書き出す前に **画像のクオリティ (Image Quality)** と **保存する画像形式 (Save Image Format)** を選択します。
