# 寸法線 (Dimension Line)

長さを示したら、対象が見えるように計測線を持ち上げます。**寸法線にはプレミアムが必要です。**

<img src="/images/tools/dimension-line/dimension-line-result.jpg" alt="青緑色の作業台に置かれた金属部品と、既存の白と黄色の寸法注釈。" style="width:100%;height:auto;border-radius:12px;" />

1. 線ツールから**寸法線 (Dimension Line)**を選択します。
2. パイプ部分の両端の間をドラッグします。
3. 計測線のハンドルを上にドラッグし、短いラベルを入力します。

この参考画像にはすでに寸法注釈が含まれています。ラベルは画像に元から含まれるもので、Annotiumによる計測値ではありません。
