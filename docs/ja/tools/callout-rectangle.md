# 吹き出し（長方形） (Callout (Rectangle))

説明が必要な箇所には、短いラベルを付けます。

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="赤い枠線の白い吹き出しに「隙間を確認」と表示され、閉じたガレージドアの小さな黄色い注意書きを指しています。" style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="白い角丸の吹き出しに「パイプを確認」と表示され、排水管を指しています。別のパイプには半透明の赤いハイライトが残っています。" style="width:100%;height:auto;border-radius:12px;" />

1. テキストツールから**吹き出し（長方形）**を選択します。
2. ドラッグしてボックスのサイズを決め、ポインターを詳細の近くに配置します。
3. 短いメモを入力し、写真を隠す場合はボックスを移動します。
4. **プロパティ (Properties)**を開き、文字サイズ、フォント、色を調整します。
5. **線 (Stroke)**で吹き出しの枠線の色と太さを選びます。
6. **塗りつぶし (Fill)**で背景色と不透明度を設定します。

ラベルは簡潔にします。ポインターだけで十分な場合は[矢印](/ja/tools/arrow)を使います。
