# ルーペ (Loupe)

元の位置を隠さずに、細部を拡大表示します。

<img src="/images/tools/loupe/loupe-result.webp" alt="円形のルーペが配管の接続部を拡大し、シンク修理の写真上でポインターが元の位置を示しています。" style="width:100%;height:auto;border-radius:12px;" />

1. フォーカスツールから**ルーペ**を選択します。
2. 描画してレンズを配置します。
3. 元の位置を細部に合わせ、レンズを調整します。

ルーペは画像の一部を拡大します。キャンバスをズームしたり移動したりする機能ではありません。
