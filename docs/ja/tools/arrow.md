# 矢印 (Arrow)

空いている場所から細部に向かってドラッグします。ドラッグの終点に矢印の先端が配置されます。

<img src="/images/tools/arrow/arrow-result.webp" alt="長い赤い矢印が露出した壁のコンセントを指し、円形のルーペで対象を拡大しています。" style="width:100%;height:auto;border-radius:12px;" />

1. 写真を開き、線ツールから**矢印**を選択します。
2. 始点から細部までドラッグします。
3. 矢印を選択して、色、太さ、終点のスタイルを変更します。

  <img src="/images/tools/arrow/arrow-tool-picker.webp" alt="コンセントとプラグの写真の上にAnnotiumのツール選択画面が開き、矢印ツールが青緑色で強調されています。" style="width:100%;height:auto;border-radius:12px;" />
  <figcaption>手順1：ツール選択画面を開き、線ツールから青緑色の矢印アイコンを選択します。</figcaption>
</figure>

<figure>
  <img src="/images/tools/arrow/arrow-drag-step.webp" alt="選択中の赤い矢印がプラグから壁のコンセントに向かって伸び、円形のルーペがコンセントの上に表示されています。" style="width:100%;height:auto;border-radius:12px;" />
  <figcaption>手順2：プラグからコンセントに向かってドラッグします。矢印が選択され、既存のルーペは対象の上に表示されたままです。</figcaption>
</figure>

<figure>
  <img src="/images/tools/arrow/arrow-properties.webp" alt="選択中の赤い矢印のプロパティに「塗りつぶし」「線」「パス」タブ、不透明度、色の選択肢、ロック解除されたスタイル設定が表示されています。" style="width:100%;height:auto;border-radius:12px;" />
  <figcaption>手順3：「プロパティ (Properties)」を開いて、選択中の矢印の見た目を変更します。</figcaption>
</figure>

上の矢印は、途切れずに一度ドラッグして描きました。プロジェクトでは注釈を編集可能な状態で保持できます。写真では端末のライブラリを使用します。
