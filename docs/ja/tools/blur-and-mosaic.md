# ぼかしとモザイク

**ぼかし (Blur)**で範囲をぼかすか、**モザイク (Mosaic)**でブロック状に置き換えます。

## ぼかし

<img src="/images/tools/blur/blur-result.webp" alt="Annotiumのぼかしツールが、サンプル請求書の選択範囲にある手書きの詳細をぼかしています。" style="width:100%;height:auto;border-radius:12px;" />

## モザイク

<img src="/images/tools/mosaic/mosaic-result.webp" alt="長方形のモザイク効果がガレージドアの注意書きの一部を覆っています。" style="width:100%;height:auto;border-radius:12px;" />

1. プライバシーツールから**ぼかし**または**モザイク**を選択します。
2. 隠したい詳細をドラッグして覆います。
3. 範囲のサイズを変更し、共有前に原寸大の結果を確認します。

ぼかしの例では、個人情報を削除したCC0のサンプル請求書を使っています。モザイクの例では、公開されているガレージの写真を使っています。個人情報を含む素材では、書き出した画像で詳細を読み取れないことを確認してください。
