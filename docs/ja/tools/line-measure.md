# 直線計測 (Line Measure)

下のガレージのドアの幅のように、対象を横切るように長さを示します。

<img src="/images/tools/line-measure/line-measure-result.webp" alt="赤い両矢印の直線計測が、ガレージのドアの中央にある掲示の上を横切り、サンプルラベル2.40 mを表示しています。" style="width:100%;height:auto;border-radius:12px;" />

1. 線ツールから**直線計測 (Line Measure)**を選択します。
2. 長さの一端からもう一端までドラッグします。
3. 短いラベルを入力し、必要に応じてテキストの位置を調整します。

ラベルの`2.40 m`はサンプルテキストで、この写真から測定した値ではありません。実際の寸法として使う前に、縮尺を設定して確認してください。**直線計測にはプレミアムが必要です。**
