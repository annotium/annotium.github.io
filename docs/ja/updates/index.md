# 新機能

このページでは、現在のガイドに反映されている主なワークフローの変更をまとめています。ストアのリリースノートに代わるものではありません。

## Annotium 4.x

- 保存した作業を管理するプロジェクトギャラリーを追加しました。
- 注釈を後から選択して修正できる、編集可能な保存済みプロジェクトを追加しました。
- 補足情報を記録できるプロジェクトのメモを追加しました。
- ドキュメントとして提出するためのPDF書き出しを追加しました。
- 任意の出力方法として、写真やギャラリーへの**自動保存 (Auto save)**を追加しました。
- 複数の画像を結合する写真のスティッチ機能を追加しました。
- 角度計測ツールと直線ツールを改善しました。
- 矢印、ハイライト、その他のオブジェクトの選択と編集を改善しました。
- 図形、テキスト、吹き出し、フリーハンド描画、切り抜き、ルーペ、スポットライト、プライバシー効果、アイコン、計測ツールのサポートを継続しています。

## 以前のガイドで扱っていた内容

以前のドキュメントでは、端末の写真の閲覧、アルバムの切り替え、削除する写真の選択、描画画面を開く操作、描画メニューやプロパティメニューからの選択を中心に説明していました。これらの内容は、[プロジェクトと写真](/ja/guide/workspaces)、[エディターの概要](/ja/guide/editor-overview)、[ツールの概要](/ja/tools/overview)に整理して引き継いでいます。
