# 使い始める

写真を開き、矢印で詳細を1つ示して、作業内容を保存しましょう。

## 写真を開く

1. ホーム画面の左上にあるワークスペース切り替えをタップします。
2. 編集可能なプロジェクトを保存するには**プロジェクト (Projects)**、端末の写真ライブラリから作業するには**写真 (Photos)**を選択します。
3. **プロジェクト**では**+**をタップして**ギャラリー (Gallery)**を選ぶか、カメラボタンを使います。**写真**ではサムネイルをタップします。

<img src="/images/getting-started/switching.jpg" alt="ホーム画面のワークスペース切り替えにプロジェクトと写真が表示されています。" width="360" />

## 最初の矢印を描く

1. ツール選択画面を開き、線ツールから**矢印 (Arrow)**を選択します。
2. 何もない場所から詳細へ向けてドラッグします。離した位置に矢印の先端が配置されます。
3. 矢印の色を変更するには、矢印を選択し、**プロパティ**を開いて、**線**の下から色を選びます。

<img src="/images/tools/arrow/arrow-drag-step.webp" alt="電源プラグから壁のコンセントに向かって矢印が伸び、両端にハンドルが表示されています。" width="360" />

## 作業を保存する

エディターで**戻る (Back)**をタップし、確認メッセージが表示されたら**保存する (Save)**を選びます。**プロジェクト**では、保存した作業がグリッドに表示されます。**写真**では注釈付き画像が通常、端末の写真ライブラリに保存されます。エディターからコピーを送信するには**エクスポート (Export)**を使います。
