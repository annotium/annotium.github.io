## 矢印の色を変更する

1. **パン (Pan)**をタップし、キャンバス上の矢印を選択します。
2. **プロパティ (Properties)**を開き、**線 (Stroke)**を選びます。
3. 色をタップします。選択した矢印の色がキャンバス上で更新されます。

<img src="/images/tools/arrow/arrow-properties.webp" alt="選択した矢印のプロパティに塗りつぶし、線、パスのタブとカラーパレットが表示されています。" width="360" />

次の注釈に使うスタイルを設定するには、選択を解除し、描画ツールを選んでから描画前にプロパティを設定します。

## 必要なプロパティを選ぶ

| 変更する項目 | 確認する場所 |
| --- | --- |
| アウトラインの色、不透明度、太さ、破線パターン | **線** |
| 閉じた図形や吹き出しの内側の色または不透明度 | **塗りつぶし (Fill)** |
| 選択中のツールの矢印の端や図形のオプション | **パス (Path)** |
| フォント、サイズ、配置、文字色 | テキスト注釈を選択したときのテキスト設定 |

表示されるコントロールは選択したツールによって異なります。一部のスタイル設定にはプレミアムが必要です。
