# プロジェクトと写真

ホーム画面の左上にあるワークスペース切り替えをタップして、**プロジェクト (Projects)**または**写真 (Photos)**を選びます。切り替えると見出しとグリッドが変わります。

<img src="/images/getting-started/switching.jpg" alt="ワークスペース切り替えにプロジェクトと写真が表示されています。" width="360" />

| ワークスペース | 選ぶ場面 | 保存されるもの |
| --- | --- | --- |
| **プロジェクト** | フォルダやプロジェクトのメモを使いたい場合や、個々の注釈を後から見直したい場合。 | 編集可能なプロジェクトです。保存済みの注釈を再び開いて編集するにはプレミアムが必要です。 |
| **写真** | 端末のアルバムにある写真に注釈を付けたい場合。 | 注釈が統合された画像です。既定の保存先は端末の写真ライブラリです。 |
