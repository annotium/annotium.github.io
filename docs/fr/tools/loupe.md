# Loupe

Affichez un gros plan sans masquer son emplacement d'origine.

<img src="/images/tools/loupe/loupe-result.webp" alt="Une loupe circulaire agrandit un raccord de plomberie tandis que sa pointe indique la source dans une photo de réparation d'évier." style="width:100%;height:auto;border-radius:12px;" />

1. Choisissez **Loupe** dans les outils de mise au point.
2. Dessinez pour placer la lentille.
3. Déplacez le point source jusqu'au détail et ajustez la lentille.

La Loupe agrandit une partie de l'image. Elle ne zoome pas sur le canevas et ne le déplace pas.
