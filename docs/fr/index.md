## Des mesures sans approximation

Annotium mesure les **angles** sur une photo. Pour les longueurs, mesurez sur place avec un ruban ou un mètre : Annotium trace alors une ligne de cote nette avec votre valeur. L’application ne déduit pas les distances à partir d’une image.
