Los proyectos son archivos de trabajo para las anotaciones que quizá quieras revisar más adelante. Conservan la imagen base, los objetos de anotación compatibles y el contexto del proyecto.

## Crear un proyecto

Abre o toma una foto, añade anotaciones y luego sal del editor mediante el flujo de guardado. El proyecto aparecerá en la cuadrícula de Proyectos.

## Volver a abrir y editar

- Con Premium, vuelve a abrir el documento guardado y sigue editando sus objetos.
- Sin Premium, crea una copia nueva aplanada y conserva intacto el proyecto original, o elige desbloquear Premium.

  src="/images/projects/items.png"

/>


## Organizar proyectos

- Crea carpetas.
- Cambia el nombre de proyectos o carpetas y muévelos.
- Duplica uno o más proyectos.
- Añade una nota al proyecto (Premium).
- Exporta una carpeta a PDF (Premium).

<img
  src="/images/projects/note.png"
  alt="Nota"
  style="max-width: 360px; width: 100%; height: auto;"
/>


## Eliminar con cuidado

Antes de eliminar un proyecto o una carpeta, confirma que hayas exportado y respaldado los archivos necesarios. Una imagen en Fotos está aplanada y no puede reemplazar el proyecto editable.

::: tip Una regla sencilla
Proyecto = archivo de trabajo. Foto o PDF = copia entregada.
:::
