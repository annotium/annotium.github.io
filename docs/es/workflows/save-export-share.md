# Guardar, exportar y compartir

## Entender los tipos de archivo

| Archivo | Ideal para | ¿Se puede editar después? |
| --- | --- | --- |
| Proyecto | Continuar el trabajo en Annotium | Sí, con el acceso correspondiente |
| JPEG o PNG | Mensajes, informes y cargas | No, queda aplanado |
| PDF | Documentos, impresión y notas de proyecto | No, es un formato de entrega |

## Guardar desde Proyectos

- Los datos del proyecto se guardan y siguen siendo editables.
- La preferencia opcional **Guardado automático (Auto save)** también guarda una imagen en la galería.

## Guardar desde Fotos

Fotos guarda una imagen aplanada; la biblioteca de fotos del dispositivo es el destino predeterminado.

## Exportar y compartir

- Exporta un JPEG.
- Exporta un PNG.
- Exporta un PDF del proyecto y elige una plantilla (Premium).
- Exporta una carpeta como PDF (Premium).
- Usa la hoja para compartir del sistema operativo.

## Calidad y formato

Elige **Calidad de la imagen (Image Quality)** y **Guardar formato de imagen (Save Image Format)** antes de exportar.
