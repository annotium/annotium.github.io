# Notas

Las notas de proyecto son una función Premium. Sirven para guardar contexto que recargaría la imagen: observaciones, identificadores, tareas pendientes o una breve explicación para tus colaboradores.

## Abrir y editar una nota

- Abre la hoja de notas desde el editor.
- Escribe en el modo **Texto enriquecido (Rich Text)**.
- Cambia al modo **Fuente Markdown (Markdown Source)**.
- Cierra la hoja y confirma cómo se conserva la nota con el proyecto.

## Añadir notas útiles

- Anota por qué se creó la anotación.
- Registra detalles que no se ven en la foto.
- Enumera tareas pendientes o un estado.
- Evita incluir información confidencial en las notas, a menos que tu forma de guardar y compartir sea adecuada para ello.

## Insertar contexto útil

- Usa **Insertar fecha y hora (Insert Date & Time)**.
- Usa **Insertar ubicación (Insert location)** después de conceder el permiso.
- Usa **Insertar enlace (Insert Link)** con un título descriptivo.

## Notas y anotaciones de texto

Usa una anotación de texto cuando las palabras deban acompañar a la imagen exportada. Usa una nota de proyecto para la información de contexto que debe seguir asociada al trabajo editable.

## Antes de compartir

Al exportar un PDF de un proyecto, elige una de estas cuatro disposiciones:

- **Imagen arriba, texto abajo (Image Above, Text Below)** coloca la imagen en la mitad superior y la nota debajo.
- **Texto arriba, imagen abajo (Text Above, Image Below)** invierte ese orden.
- **Texto a la izquierda, imagen a la derecha (Text Left, Image Right)** coloca la nota a la izquierda y la imagen a la derecha.
- **Imagen a la izquierda, texto a la derecha (Image Left, Text Right)** invierte la disposición lado a lado.

La nota se presenta como texto con formato. Revisa el PDF antes de compartirlo para confirmar
que la nota y la imagen se lean bien con la disposición elegida.
