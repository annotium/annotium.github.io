# Novedades

Esta página resume los principales cambios en el flujo de trabajo que refleja la guía actual. No sustituye las notas de publicación de la tienda.

## Annotium 4.x

- Se añadió una galería de proyectos para el trabajo guardado.
- Se añadieron proyectos guardados editables para poder seleccionar y modificar las anotaciones más adelante.
- Se añadieron notas de proyecto para guardar contexto complementario.
- Se añadió la exportación a PDF para entregar documentos.
- Se añadió **Guardado automático en Fotos/galería (Auto save to photo/gallery)** como flujo opcional para guardar resultados.
- Se añadió la unión de fotos para combinar varias imágenes.
- Se mejoraron las herramientas de ángulo y línea.
- Se mejoraron la selección y edición de flechas, resaltados y otros objetos.
- Se siguió dando soporte a formas, texto, llamadas, dibujo libre, recorte, lupa, foco, efectos de privacidad, iconos y herramientas de medición.

## Cobertura de guías anteriores

La documentación anterior se centraba en explorar las fotos del dispositivo, cambiar de álbum, seleccionar fotos para eliminarlas, abrir la pantalla de dibujo y elegir opciones en los menús de dibujo y propiedades. Esos temas se conservaron y reorganizaron en [Proyectos y Fotos](/es/guide/workspaces),
[Vista general del editor](/es/guide/editor-overview) y [Vista general de las herramientas](/es/tools/overview).
