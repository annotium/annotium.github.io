## Cambiar el color de una flecha

1. Toca **Desplazar (Pan)** y selecciona una flecha en el lienzo.
2. Abre **Propiedades (Properties)** y elige **Trazo (Stroke)**.
3. Toca un color. La flecha seleccionada se actualizará en el lienzo.

<img src="/images/tools/arrow/arrow-properties.webp" alt="Las Propiedades de la flecha seleccionada muestran las pestañas Relleno, Trazo y Trazado, además de una paleta de colores." width="360" />

Para establecer un estilo para la siguiente anotación, quita la selección, elige una herramienta de dibujo y configura sus propiedades antes de dibujar.

## Elegir la propiedad que necesitas

| Para cambiar | Busca |
| --- | --- |
| Color del contorno, opacidad, ancho o patrón de trazo | **Trazo (Stroke)** |
| Color u opacidad dentro de una forma cerrada o una llamada | **Relleno (Fill)** |
| Opciones de extremos de flecha o geometría de la herramienta seleccionada | **Trazado (Path)** |
| Fuente, tamaño, alineación o color del texto | Ajustes de texto en una anotación de texto seleccionada |

Los controles disponibles dependen de la herramienta seleccionada. Algunos controles de estilo requieren Premium.
