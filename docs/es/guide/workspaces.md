# Proyectos y Fotos

Toca el selector de espacio de trabajo en la parte superior izquierda de la pantalla de inicio para elegir **Proyectos (Projects)** o **Fotos (Photos)**. El encabezado y la cuadrícula cambian al alternar entre ellos.

<img src="/images/getting-started/switching.jpg" alt="El selector de espacio de trabajo muestra Proyectos y Fotos." width="360" />

| Espacio de trabajo | Elígelo cuando | Resultado guardado |
| --- | --- | --- |
| **Proyectos (Projects)** | Quieras carpetas, notas de proyecto o la posibilidad de volver a cada anotación. | Un proyecto editable. Para volver a abrir sus anotaciones existentes necesitas Premium. |
| **Fotos (Photos)** | Quieras anotar una foto de un álbum del dispositivo. | Una imagen aplanada con las anotaciones integradas. El destino predeterminado es la fototeca del dispositivo. |
