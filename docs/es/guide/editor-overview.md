## Encontrar herramientas y controles

<img src="/images/tools/arrow/arrow-tool-picker.webp" alt="El editor del teléfono muestra el selector de herramientas abierto sobre una foto, con Flecha resaltada." width="360" />

- **Herramientas (Tools)** abre el selector de herramientas. Elige una herramienta y dibuja en la foto.
- **Propiedades (Properties)** cambia la anotación seleccionada o los valores predeterminados de la herramienta activa.
- **Deshacer (Undo)** y **Rehacer (Redo)** recorren los cambios del editor. **Atrás (Back)** cierra el editor y te pide guardar si es necesario.
- **Exportar (Export)** abre las opciones para enviar una copia. Un proyecto también puede incluir una [nota](/es/workflows/notes).

En tabletas, busca la barra de herramientas a la izquierda y el inspector de propiedades a la derecha.

## Desplazarse por el lienzo

Pellizca con dos dedos para acercar o alejar. Cuando tengas el zoom ampliado, arrastra con dos dedos para ver otra parte de la foto. Con una herramienta de dibujo activa, toca dos veces un área vacía del lienzo para volver a ajustar la imagen.
