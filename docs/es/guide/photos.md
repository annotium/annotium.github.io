# Explorar las fotos del dispositivo

## Abrir una foto

1. Cambia a **Fotos (Photos)** desde la pantalla de inicio.
2. Permite el acceso a las fotos si tu dispositivo te lo solicita. Si denegaste el acceso, toca **Abrir Configuración (Open Settings)** y revisa los permisos de fotos de Annotium.
3. Toca el título del álbum para elegir un álbum y luego toca una foto para editarla.

<img src="/images/photos/browse.png" alt="El espacio de trabajo Fotos muestra el título de un álbum sobre una cuadrícula de miniaturas." width="360" />

Desliza hacia abajo en la cuadrícula para actualizarla. Para empezar con una foto nueva, usa el botón de la cámara. Con Premium, abre **+ → Componer (Compose)** para [combinar varias fotos](/es/tools/images-compose#compose-photos).

## Guardar una imagen anotada

Toca **Atrás (Back)** y elige **Guardar (Save)** cuando se te indique. Fotos guarda una imagen aplanada, y la fototeca del dispositivo es el destino predeterminado. Para poder editar las anotaciones más adelante, empieza en [Proyectos](/es/guide/projects).

## Eliminar fotos

Mantén presionada una miniatura, toca otras fotos para seleccionarlas y luego elige **Eliminar (Delete)** y revisa la confirmación.

<img src="/images/photos/delete.png" alt="El espacio de trabajo Fotos muestra miniaturas seleccionadas y los controles para administrar la selección." width="360" />

::: danger Fototeca del dispositivo
Al eliminar aquí, se quitan las fotos de la fototeca de tu dispositivo. La función Deshacer de Annotium se aplica a las acciones del editor.
:::
