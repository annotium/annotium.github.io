# Preguntas frecuentes

## ¿Por qué no puedo seleccionar una anotación en una foto exportada?

Las exportaciones a foto y PDF son archivos finales aplanados. Abre el proyecto guardado de Annotium para editar objetos individuales.

## ¿Dónde está la imagen que guardé?

Revisa la aplicación Fotos o Galería de tu dispositivo y confirma que Annotium tenga permiso para añadir imágenes. Si el **Guardado automático (Auto save)** está desactivado, usa la opción para guardar o compartir explícitamente.

## ¿Por qué veo imágenes duplicadas?

Es posible que el **Guardado automático (Auto save)** esté activado y que también guardes manualmente. Desactiva el guardado automático o usa siempre la misma forma de completar la acción.

## ¿Puedo modificar un proyecto antiguo?

Los usuarios Premium pueden volver a abrir el documento guardado y modificar sus objetos. Sin
Premium, Annotium puede crear una copia nueva aplanada y mantener intacto el proyecto original.

## ¿Debo usar una nota o un cuadro de texto?

Usa una nota para el contexto del proyecto; usa un cuadro de texto cuando las palabras deban aparecer en la imagen exportada.

## ¿Los valores de ángulo y distancia son exactos?

Dependen de la ubicación de los puntos, la escala de la imagen y la perspectiva. Considéralos anotaciones visuales, a menos que tu flujo de trabajo esté calibrado.

## ¿Puedo combinar varias capturas de pantalla?

Usa [Imágenes y composición](/es/tools/images-compose) para crear un collage o
unir imágenes vertical u horizontalmente y, luego, anota el resultado combinado.
