## Dar estilo a una forma

- Activa o desactiva el trazo y el relleno cuando sea posible.
- Define el grosor, el color y la opacidad del contorno.
- Elige un relleno sólido o con patrón.
- Cambia el tamaño y la forma con los controles.

## Ejemplos sugeridos

Usa una tarea real para cada familia de herramientas: enmarca un defecto, rodea un control, marca un área
irregular y señala una pieza anular.
