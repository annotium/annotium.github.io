### Llamada (óvalo) (Callout (Oval))

Usa una llamada ovalada para una nota breve cuando el puntero deba señalar un detalle cercano.

<img src="/images/tools/callout-oval-result.webp" alt="Una llamada ovalada con el texto Revisar espacio apunta a una bisagra en una puerta de madera desgastada." style="width:100%;height:auto;border-radius:12px;" />

Elige **Llamada (óvalo) (Callout (Oval))**, introduce una etiqueta breve y coloca la punta del puntero sobre el detalle. Esta captura manual de iPhone 18 muestra la llamada sobre una bisagra.

## Llamadas expresivas

- Texto de nube (Cloud Text) (Premium).
- Texto de explosión (Burst Text) (Premium).
- Globo de pensamiento (Thought Bubble) (Premium).

Globo de pensamiento sirve para escribir una idea o alternativa breve en una superficie de planificación.

## Dar formato al texto

- Elige una familia tipográfica y un tamaño.
- Cambia el color y la opacidad del texto.
- Aplica negrita, cursiva, tachado y alineación.
- Da formato al contorno y al relleno de la llamada por separado, cuando esté disponible.

## Mover el puntero

Selecciona una llamada para mostrar sus controles. Arrastra el cuerpo para mover la etiqueta y arrastra el control del puntero para dirigir su extremo hacia un detalle.
