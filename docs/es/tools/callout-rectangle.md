# Llamada (rectángulo)

Usa una etiqueta breve cuando el detalle necesite una explicación.

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="Una llamada blanca con contorno rojo y el texto Revisar espacio apunta directamente al pequeño aviso amarillo en la puerta cerrada de un garaje." style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="Una llamada rectangular blanca redondeada con el texto Revisar tubería apunta a un tubo de desagüe; un Resaltado rojo translúcido permanece sobre otra tubería." style="width:100%;height:auto;border-radius:12px;" />

1. Elige **Llamada (rectángulo) (Callout (Rectangle))** en las herramientas de Texto (Text tools).
2. Arrastra para definir el tamaño del cuadro y coloca el puntero cerca del detalle.
3. Escribe una nota breve y luego mueve el cuadro si tapa la foto.
4. Abre **Propiedades (Properties)** para ajustar el tamaño, la fuente o el color del texto.
5. Usa **Trazo (Stroke)** para elegir el color y el ancho del contorno de la llamada.
6. Usa **Relleno (Fill)** para elegir un color de fondo y definir su opacidad.
