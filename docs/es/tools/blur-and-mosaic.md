# Desenfoque y mosaico

Usa **Desenfoque (Blur)** para suavizar un área o **Mosaico (Mosaic)** para cubrirla con bloques.

## Desenfoque

<img src="/images/tools/blur/blur-result.webp" alt="La herramienta Desenfoque de Annotium suaviza los detalles escritos a mano en un área seleccionada de una factura de muestra." style="width:100%;height:auto;border-radius:12px;" />

## Mosaico

<img src="/images/tools/mosaic/mosaic-result.webp" alt="Un efecto de mosaico rectangular cubre parte de un aviso en la puerta de un garaje." style="width:100%;height:auto;border-radius:12px;" />

1. Elige **Desenfoque** o **Mosaico** en las herramientas de privacidad (privacy tools).
2. Arrastra sobre el detalle que quieras ocultar.
3. Cambia el tamaño del área e inspecciona el resultado a tamaño completo antes de compartirlo.

El ejemplo de Desenfoque usa una factura de muestra CC0 a la que se le quitaron los datos personales. El ejemplo de Mosaico usa una foto pública de un garaje. Si el material es privado, comprueba que no se pueda leer el detalle en la copia exportada.
