## Draw freehand

- Select the freehand tool.
- Draw one continuous stroke.
- Change its width, color, opacity, and line style.

## Highlight an area

- Select the highlight tool.
- Sweep over text or a region of the image.
- Adjust width, color, and opacity for readability.

## Improve pen and finger control

- Set **Touch Point Area** for a stylus, medium finger target, or large finger
  target.
- Turn the finger-following loupe on or off.
- Zoom before drawing fine details.
- Use Undo and redraw a stroke that is not accurate enough.
