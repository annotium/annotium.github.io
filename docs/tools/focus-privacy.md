# Focus and privacy

<p class="guide-outline">
  Outline · This page is ready for verified steps and current screenshots.
</p>

## Magnify a detail

- Add a Loupe object.
- Move the source area and magnified lens.
- Adjust the magnification ratio.

## Spotlight an area

- Draw a freeform spotlight.
- Draw a rectangular spotlight.
- Choose the spotlight style where supported.

## Obscure private information

- Use blur or obfuscation.
- Use mosaic pixelation.
- Adjust pixel cell size and effect amount.

## Advanced pixel effects

- Crystallize (Premium).
- Mezzotint (Premium).
- Pointillize (Premium).
- Color halftone (Premium).
