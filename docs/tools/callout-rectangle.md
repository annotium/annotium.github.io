# Callout (Rectangle)

Connect a short instruction to its target so the reader can see what the note refers to.

<img src="/images/tool-scenes/closed-garage-door.jpg" alt="A closed garage door photographed from the front." style="width:100%;height:auto;border-radius:12px;" />

## Add a callout

1. Choose **Callout (Rectangle)** from the text tools.
2. Place the callout near the detail.
3. Enter a short label, such as “Check clearance”.
4. Move the pointer to the exact detail and reposition the box if it covers the photo.
5. Adjust the text and outline so both remain clear at phone size.

Keep the note short. Use a separate [Arrow](/tools/arrow) when a simple pointer is enough.

::: tip Projects or Photos?
Use **Projects** to keep the callout editable. Use **Photos** to work from your device library and save a finished image there.
:::
