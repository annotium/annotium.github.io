# Callout (Rectangle)

Use a brief label when the detail needs an explanation.

<img src="/images/tool-scenes/closed-garage-door.jpg" alt="A closed garage door with small notices that can be used as callout targets." style="width:100%;height:auto;border-radius:12px;" />

1. Choose **Callout (Rectangle)** from the text tools.
2. Drag to set the box size and place its pointer near the detail.
3. Enter a short note, then move the box if it obscures the photo.

Keep the label concise. Use an [Arrow](/tools/arrow) when a pointer alone is enough.
