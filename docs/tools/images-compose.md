# Images and composition

<p class="guide-outline">
  Outline · This page is ready for verified steps and current screenshots.
</p>

## Insert an image

- Explain the Premium requirement before opening the picker.
- Pick an image and place it over the base image.
- Move and resize the inserted image.

## Copy an image region

- Select the copy tool and mark a region.
- Reposition the copied region.
- Confirm or cancel the copy operation.

## Crop

- Enter crop mode.
- Move each edge or corner.
- Confirm or cancel the crop.
- Explain that cropping changes the project's base image.

## Compose photos

Document the Premium composition modes:

- Collage.
- Stitch vertically.
- Stitch horizontally.
- Add, reorder, and remove source photos.
