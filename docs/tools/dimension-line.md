# Dimension Line

Show which two points a distance refers to. **Dimension Line requires Premium.** Availability and purchase options appear in the app and may vary by store region.

<img src="/images/tool-scenes/technician-pipe.jpg" alt="A technician working on plumbing inside a wall." style="width:100%;height:auto;border-radius:12px;" />

## Place a dimension line

1. Choose **Dimension Line** from the line tools.
2. Mark the two points whose distance you want to show.
3. Position the dimension rail so it does not hide the feature.
4. Select the line to adjust the label and appearance.

A photo does not establish a real-world scale by itself. Use a known reference and explain how the value was set before sharing a measurement as more than a visual note.

::: tip Projects or Photos?
Use **Projects** to keep the dimension annotation editable. Use **Photos** to work from your device library and save a finished image there.
:::
