# Dimension Line

Mark a span, then lift its measurement rail so the object stays visible. **Dimension Line requires Premium.**

<img src="/images/tools/dimension-line/dimension-line-result.jpg" alt="A metal component on a teal work surface with existing white and yellow dimension annotations." style="width:100%;height:auto;border-radius:12px;" />

1. Choose **Dimension Line** from the line tools.
2. Drag between the two ends of the pipe section.
3. Drag the rail handle upward and enter a short label.

This reference image already contains dimension annotations. Its labels are part of the supplied image and are not Annotium measurements.
