# Blur and Mosaic

Cover private details before sharing. **Blur** softens the selected area; **Mosaic** replaces it with visible blocks.

<img src="/images/tool-scenes/blank-clipboard.jpg" alt="A blank clipboard and paper ready for a privacy-safe annotation example." style="width:100%;height:auto;border-radius:12px;" />

## Conceal a detail

1. Choose **Blur** or **Mosaic** from the privacy tools.
2. Draw over the text or image area to conceal.
3. Resize the covered area to include the full detail.
4. Adjust the effect and inspect the exported image before sharing.

Blur and Mosaic are different visual effects. Check the final saved copy at full size to make sure the detail cannot be read.

::: warning Use fictional examples
This guide uses made-up work-ticket details. Never include a real address, account number, face, or location in documentation images.
:::

::: tip Projects or Photos?
Use **Projects** to keep the effect editable. Use **Photos** to work from your device library and save a finished image there.
:::
