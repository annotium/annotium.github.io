# Line Measure

Mark a span directly across the feature, like the garage-door width below.

<img src="/images/tools/line-measure/line-measure-result.webp" alt="A red two-ended Line Measure spans the garage door above its center notice and displays the sample label 2.40 m." style="width:100%;height:auto;border-radius:12px;" />

1. Choose **Line Measure** from the line tools.
2. Drag from one end of the span to the other.
3. Enter a short label and adjust its text placement if needed.

The `2.40 m` label is sample text, not a value measured from this photo. Set and verify a scale before using a measurement as a real-world dimension. **Line Measure requires Premium.**
