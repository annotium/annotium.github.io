# Troubleshooting

<p class="guide-outline">
  Outline · This page is ready for verified steps and current screenshots.
</p>

## Photos or albums do not appear

Open your device settings and allow Annotium to access the required photos. Limited-library access may show only selected items; add more photos to the allowed set or change the permission.

## The camera does not open

Allow camera access in device settings, then reopen Annotium. Also check whether another app or device policy is restricting the camera.

## A location marker cannot be added

Allow location access in device settings, return to Annotium, and retry. The
location marker also requires Premium.

## A saved image is missing

Determine whether the edit started in Projects or Photos. Confirm photo-library
permission and available device storage. Check output format and **Auto save**,
then look in Recents or the platform's default gallery.

## I cannot edit an exported result

Open the corresponding project. If only a flattened image remains, you can
annotate that image again, but its existing marks cannot be selected separately.

## Export looks soft or text is too small

Use the highest suitable output quality, reduce unnecessary cropping or enlargement, and preview at the recipient’s expected display size. Enlarge text and line widths before exporting.

## A font cannot be imported

- Use a valid TTF or OTF file.
- Choose a unique font-family name.
- Check network access before downloading catalog fonts.

## An object is difficult to select

Zoom in, switch explicitly to selection mode, and tap an exposed edge or handle. Move a covering object temporarily if several annotations overlap.

## Premium is not recognized

- Confirm the device is signed into the purchasing store account.
- Open **Purchases** and restore the purchase.
- Check the store connection and try again later.
- Contact support with Annotium version and build number, but never include
  payment credentials.

## Still stuck?

Record your platform, Annotium version, the action you attempted, and whether the issue affects one project or every project. Include a screen recording only after removing private information.
