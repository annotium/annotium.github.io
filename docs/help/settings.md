# Settings

<p class="guide-outline">
  Outline · This page is ready for verified steps and current screenshots.
</p>

Open **About** from the information button on either home workspace. The screen
contains purchases, editor preferences, output preferences, fonts, help, and
support.

## Appearance and interaction

- Dark Mode.
- Show Loupe while touching the canvas.
- Cursor color.
- Touch Point Area for stylus or finger input.
- Snap for supported line and angle tools.

## Saving and output

- Auto save an editable project as an image to the gallery.
- Default image format.
- Image quality.

## Fonts

- Manage installed fonts.
- Import a TTF or OTF file.
- Browse and download fonts from the catalog (Premium).
- View font attribution.

## Purchases and support

- View purchases and restore a previous purchase.
- Open this user guide.
- Contact support and include the app version and build number.
