# Frequently asked questions

## Why can’t I select an annotation in an exported photo?

Photo and PDF exports are flattened delivery files. Open the saved Annotium project to edit individual objects.

## Where did my saved image go?

Check the device’s Photos or Gallery app and confirm Annotium has permission to add images. If auto-save is disabled, use the explicit save or share action.

## Why do I see duplicate images?

Auto save may be enabled while you are also saving manually. Disable auto-save or use one completion path consistently.

## Can I revise an old project?

Premium users can reopen the saved document and revise its objects. Without
Premium, Annotium can create a new flattened copy while keeping the original
project unchanged.

## Should I use a note or a text box?

Use a note for project context; use a text box when the words must appear in the exported image.

## Are angle and distance values exact?

They depend on point placement, image scale, and perspective. Treat them as visual annotations unless your workflow is calibrated.

## Can I combine several screenshots?

Use [Images and composition](/tools/images-compose) to create a collage or
stitch images vertically or horizontally, then annotate the combined result.
