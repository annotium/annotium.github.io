# เส้นวัดขนาด

กำหนดช่วง แล้วเลื่อนเส้นวัดขึ้นเพื่อให้มองเห็นวัตถุได้ชัดเจน **เส้นวัดขนาดต้องใช้พรีเมียม (Premium)**

<img src="/images/tools/dimension-line/dimension-line-result.jpg" alt="ชิ้นส่วนโลหะบนพื้นผิวทำงานสีเขียวอมฟ้า พร้อมคำอธิบายขนาดสีขาวและสีเหลืองที่มีอยู่แล้ว" style="width:100%;height:auto;border-radius:12px;" />

1. เลือก **เส้นวัดขนาด (Dimension Line)** จากเครื่องมือเส้น
2. ลากระหว่างปลายทั้งสองด้านของส่วนท่อ
3. ลากที่จับเส้นวัดขึ้นด้านบนแล้วป้อนป้ายกำกับสั้น ๆ

รูปอ้างอิงนี้มีคำอธิบายขนาดอยู่แล้ว ป้ายกำกับเหล่านั้นเป็นส่วนหนึ่งของรูปภาพที่ให้มา ไม่ใช่ค่าที่วัดด้วย Annotium
