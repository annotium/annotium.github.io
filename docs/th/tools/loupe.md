# แว่นขยาย

แสดงภาพระยะใกล้โดยไม่ซ่อนตำแหน่งต้นทาง

<img src="/images/tools/loupe/loupe-result.webp" alt="แว่นขยายวงกลมขยายจุดเชื่อมต่อท่อ ขณะที่ตัวชี้ระบุตำแหน่งต้นทางในภาพซ่อมแซมซิงก์" style="width:100%;height:auto;border-radius:12px;" />

1. เลือก **แว่นขยาย (Loupe)** จากเครื่องมือเน้นจุดสำคัญ
2. วาดเพื่อวางเลนส์
3. ย้ายจุดต้นทางไปยังรายละเอียด แล้วปรับเลนส์

แว่นขยายขยายบางส่วนของรูปภาพ โดยไม่ซูมหรือเลื่อนแคนวาส
