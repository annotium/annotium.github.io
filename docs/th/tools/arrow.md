# ลูกศร

ลากจากพื้นที่ว่างไปยังรายละเอียด ปลายลูกศรจะอยู่ที่จุดสิ้นสุดของการลาก

<img src="/images/tools/arrow/arrow-result.webp" alt="ลูกศรสีแดงยาวชี้ไปยังเต้ารับติดผนังที่เปิดให้เห็น โดยมีแว่นขยายวงกลมขยายเป้าหมาย" style="width:100%;height:auto;border-radius:12px;" />

1. เปิดรูปภาพแล้วเลือก **ลูกศร (Arrow)** จากเครื่องมือเส้น
2. ลากจากจุดเริ่มต้นไปยังรายละเอียด
3. เลือกลูกศรเพื่อเปลี่ยนสี ความกว้าง หรือรูปแบบปลายเส้น

  <figcaption>ขั้นตอนที่ 1: เปิดตัวเลือกเครื่องมือแล้วเลือกไอคอนลูกศรสีเขียวอมฟ้าในกลุ่มเครื่องมือเส้น</figcaption>

  <img src="/images/tools/arrow/arrow-drag-step.webp" alt="ลูกศรสีแดงที่เลือกไว้ลากจากปลั๊กไปยังเต้ารับติดผนัง โดยมีแว่นขยายวงกลมอยู่เหนือเต้ารับ" style="width:100%;height:auto;border-radius:12px;" />

  <figcaption>ขั้นตอนที่ 3: เปิดคุณสมบัติเพื่อเปลี่ยนลักษณะของลูกศรที่เลือก</figcaption>
</figure>

ลูกศรด้านบนวาดด้วยการลากต่อเนื่องเพียงครั้งเดียว โปรเจกต์จะเก็บคำอธิบายไว้ให้แก้ไขได้ ส่วนรูปภาพใช้รูปจากคลังในอุปกรณ์ของคุณ
