# วัดระยะเส้น

กำหนดช่วงพาดผ่านส่วนที่ต้องการวัดโดยตรง เช่น ความกว้างของประตูโรงรถด้านล่าง

<img src="/images/tools/line-measure/line-measure-result.webp" alt="เส้นวัดระยะสีแดงแบบมีหัวลูกศรสองด้านพาดผ่านประตูโรงรถเหนือป้ายตรงกลาง และแสดงป้ายตัวอย่าง 2.40 m" style="width:100%;height:auto;border-radius:12px;" />

1. เลือก **วัดระยะเส้น (Line Measure)** จากเครื่องมือเส้น
2. ลากจากปลายด้านหนึ่งของช่วงไปยังอีกด้าน
3. ป้อนป้ายกำกับสั้น ๆ แล้วปรับตำแหน่งข้อความหากจำเป็น

ป้าย `2.40 m` เป็นข้อความตัวอย่าง ไม่ใช่ค่าที่วัดจากรูปนี้ ตั้งค่าและตรวจสอบสเกลก่อนนำค่าที่วัดไปใช้เป็นขนาดจริง **เครื่องมือวัดระยะเส้นต้องใช้พรีเมียม (Premium)**
