# คำบรรยาย (สี่เหลี่ยม)

ใช้ป้ายกำกับสั้น ๆ เมื่อจำเป็นต้องอธิบายรายละเอียด

<img src="/images/tools/callout-rectangle/callout-rectangle-result.webp" alt="คำบรรยายพื้นขาวขอบแดงที่มีข้อความ Check clearance ชี้ตรงไปยังป้ายสีเหลืองเล็ก ๆ บนประตูโรงรถที่ปิดอยู่" style="width:100%;height:auto;border-radius:12px;" />

<img src="/images/tools/callout-rectangle/callout-pipe-result.webp" alt="คำบรรยายสี่เหลี่ยมมุมโค้งสีขาวที่มีข้อความ Check pipe ชี้ไปยังท่อระบายน้ำ โดยมีไฮไลต์สีแดงโปร่งแสงบนท่ออีกเส้น" style="width:100%;height:auto;border-radius:12px;" />

1. เลือก **คำบรรยาย (สี่เหลี่ยม) (Callout (Rectangle))** จากเครื่องมือข้อความ
2. ลากเพื่อกำหนดขนาดกล่อง แล้ววางตัวชี้ใกล้รายละเอียด
3. ป้อนโน้ตสั้น ๆ แล้วย้ายกล่องหากบังรูปภาพ
4. เปิด **คุณสมบัติ (Properties)** เพื่อปรับขนาดข้อความ แบบอักษร หรือสี
5. ใช้ **เส้นขอบ (Stroke)** เพื่อเลือกสีและความกว้างของเส้นขอบคำบรรยาย
6. ใช้ **เติม (Fill)** เพื่อเลือกสีพื้นหลังและกำหนดความทึบ
