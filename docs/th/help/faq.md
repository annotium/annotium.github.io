# คำถามที่พบบ่อย

## ทำไมฉันจึงเลือกคำอธิบายในรูปภาพที่ส่งออกไม่ได้?

การส่งออกรูปภาพและ PDF จะรวมองค์ประกอบทั้งหมดเป็นไฟล์เดียวที่ไม่สามารถแก้ไขวัตถุแยกชิ้นได้ หากต้องการแก้ไขวัตถุแต่ละชิ้น ให้เปิดโปรเจกต์ Annotium ที่บันทึกไว้

## รูปภาพที่บันทึกไว้ของฉันอยู่ที่ไหน?

ตรวจสอบแอปรูปภาพ (Photos) หรือแกลเลอรี (Gallery) ในอุปกรณ์ และยืนยันว่า Annotium ได้รับอนุญาตให้เพิ่มรูปภาพ หากปิดบันทึกอัตโนมัติ (Auto save) ให้ใช้คำสั่งบันทึกหรือแชร์ (Share) โดยตรง

## ทำไมฉันจึงเห็นรูปภาพซ้ำ?

อาจเปิดบันทึกอัตโนมัติไว้พร้อมกับบันทึกด้วยตนเอง ให้ปิดการบันทึกอัตโนมัติหรือใช้วิธีบันทึกให้เสร็จเพียงวิธีเดียวอย่างสม่ำเสมอ

## ฉันแก้ไขโปรเจกต์เก่าได้ไหม?

ผู้ใช้พรีเมียมสามารถเปิดเอกสารที่บันทึกไว้อีกครั้งและแก้ไขวัตถุได้ หากไม่มีพรีเมียม Annotium สามารถสร้างสำเนาใหม่ที่รวมองค์ประกอบทั้งหมด โดยโปรเจกต์ต้นฉบับยังคงเดิม

## ควรใช้โน้ตหรือกล่องข้อความ?

ใช้โน้ตเพื่อเพิ่มบริบทให้โปรเจกต์ และใช้กล่องข้อความเมื่อจำเป็นต้องให้ข้อความปรากฏในรูปภาพที่ส่งออก

## ค่ามุมและระยะทางแม่นยำหรือไม่?

ค่าดังกล่าวขึ้นอยู่กับตำแหน่งจุด มาตราส่วนของรูปภาพ และมุมมอง ให้ใช้เป็นคำอธิบายประกอบเชิงภาพ เว้นแต่เวิร์กโฟลว์ของคุณจะผ่านการปรับเทียบแล้ว

## รวมภาพหน้าจอหลายภาพเข้าด้วยกันได้ไหม?

ใช้ [รูปภาพและการจัดองค์ประกอบ](/th/tools/images-compose) เพื่อสร้างคอลลาจหรือเย็บต่อรูปภาพในแนวตั้งหรือแนวนอน จากนั้นจึงเพิ่มคำอธิบายประกอบ
