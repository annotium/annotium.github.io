# มีอะไรใหม่

หน้านี้สรุปการเปลี่ยนแปลงสำคัญของเวิร์กโฟลว์ที่แสดงอยู่ในคู่มือฉบับปัจจุบัน ไม่ได้ใช้แทนบันทึกการเผยแพร่ในสโตร์

## Annotium 4.x

- เพิ่มแกลเลอรีโปรเจกต์สำหรับงานที่บันทึกไว้
- เพิ่มโปรเจกต์ที่บันทึกและแก้ไขได้ เพื่อให้เลือกและปรับคำอธิบายประกอบภายหลังได้
- เพิ่มโน้ตของโปรเจกต์สำหรับข้อมูลบริบทประกอบ
- เพิ่มการส่งออก PDF สำหรับส่งมอบในรูปแบบเอกสาร
- เพิ่ม **บันทึกอัตโนมัติไปยังรูปภาพ/แกลเลอรี (Auto save to photo/gallery)** เป็นเวิร์กโฟลว์เสริมสำหรับบันทึกผลลัพธ์
- เพิ่มการเย็บต่อรูปภาพเพื่อรวมภาพหลายรูป
- ปรับปรุงเครื่องมือวัดมุมและวัดระยะเส้น
- ปรับปรุงการเลือกและแก้ไขลูกศร ไฮไลต์ และวัตถุอื่น ๆ
- รองรับรูปทรง ข้อความ คำบรรยาย การวาดอิสระ การครอป แว่นขยาย สปอตไลต์ เอฟเฟกต์ความเป็นส่วนตัว ไอคอน และเครื่องมือวัดระยะอย่างต่อเนื่อง

## เนื้อหาในคู่มือฉบับก่อน

เอกสารเดิมเน้นการเรียกดูรูปภาพในอุปกรณ์ การเปลี่ยนอัลบั้ม การเลือกรูปภาพเพื่อลบ การเปิดหน้าจอวาด และการเลือกจากเมนูวาดหรือคุณสมบัติ แนวคิดเหล่านี้ยังคงอยู่และจัดหมวดหมู่ใหม่ใน [โปรเจกต์และรูปภาพ](/th/guide/workspaces), [ภาพรวมหน้าแก้ไข](/th/guide/editor-overview) และ [ภาพรวมเครื่องมือ](/th/tools/overview)

::: info ก่อนเผยแพร่ข้อมูลเวอร์ชันที่เจาะจง
ตรวจสอบหมายเลขเวอร์ชันที่แน่นอน ความพร้อมใช้งานในแต่ละแพลตฟอร์ม และชื่อ UI กับ App Store/Play Store เวอร์ชันปัจจุบันและแอปที่เผยแพร่จริง
:::
