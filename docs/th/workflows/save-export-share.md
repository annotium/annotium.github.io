# บันทึก ส่งออก และแชร์

## ทำความเข้าใจประเภทไฟล์ผลลัพธ์

| ผลลัพธ์ | เหมาะสำหรับ | แก้ไขภายหลังได้หรือไม่? |
| --- | --- | --- |
| โปรเจกต์ | ทำงานต่อใน Annotium | ได้ โดยขึ้นอยู่กับสิทธิ์การเข้าถึงที่เกี่ยวข้อง |
| JPEG หรือ PNG | การส่งข้อความ รายงาน และการอัปโหลด | ไม่ได้ เป็นภาพที่รวมชั้นภาพแล้ว |
| PDF | เอกสาร การพิมพ์ และโน้ตของโปรเจกต์ | ไม่ได้ เป็นรูปแบบสำหรับส่งมอบ |

## บันทึกจากหน้า **โปรเจกต์ (Projects)**

- ข้อมูลโปรเจกต์จะถูกบันทึกและยังแก้ไขได้
- คุณเลือกเปิดใช้การตั้งค่า **บันทึกอัตโนมัติ (Auto save)** เพื่อบันทึกรูปภาพลงในแกลเลอรีเพิ่มเติมได้

## บันทึกจากหน้า **รูปภาพ (Photos)**

รูปภาพจะบันทึกภาพที่รวมชั้นภาพแล้ว โดยใช้คลังรูปภาพของอุปกรณ์เป็นตำแหน่งปลายทางเริ่มต้น

## ส่งออกและแชร์

- ส่งออกเป็น JPEG
- ส่งออกเป็น PNG
- ส่งออกโปรเจกต์เป็น PDF และเลือกเทมเพลต (พรีเมียม)
- ส่งออกโฟลเดอร์เป็น PDF (พรีเมียม)
- ใช้แผงแชร์ของระบบปฏิบัติการ

## คุณภาพและรูปแบบไฟล์

เลือก **คุณภาพรูปภาพ (Image Quality)** และ **รูปแบบไฟล์รูปภาพที่บันทึก (Save Image Format)** ก่อนส่งออก
