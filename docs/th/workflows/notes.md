# โน้ต

โน้ตของโปรเจกต์เป็นฟีเจอร์พรีเมียม ใช้เก็บบริบทที่อาจทำให้ภาพมีข้อมูลแน่นเกินไป เช่น ข้อสังเกต รหัสรายการ สิ่งที่ต้องติดตาม หรือคำอธิบายสั้น ๆ สำหรับผู้ร่วมงาน

## เปิดและแก้ไขโน้ต

- เปิดแผ่นโน้ตจากหน้าแก้ไข
- เขียนในโหมดข้อความมีสไตล์ (Rich Text)
- สลับไปยังโหมดซอร์สมาร์กดาวน์ (Markdown Source)
- ปิดแผ่นโน้ตและตรวจสอบว่าโน้ตถูกเก็บไว้กับโปรเจกต์อย่างไร

## เพิ่มข้อมูลที่เป็นประโยชน์ในโน้ต

- บันทึกเหตุผลที่สร้างคำอธิบายประกอบ
- จดรายละเอียดที่มองไม่เห็นในรูปภาพ
- ระบุสิ่งที่ต้องติดตามหรือสถานะ
- หลีกเลี่ยงการใส่ข้อมูลลับในโน้ต เว้นแต่ระบบจัดเก็บและวิธีแชร์ของคุณจะเหมาะสมกับข้อมูลนั้น

## แทรกบริบทที่เป็นประโยชน์

- แทรกวันที่และเวลา
- แทรกตำแหน่งที่ตั้งหลังจากอนุญาตให้เข้าถึง
- เพิ่มลิงก์พร้อมชื่อที่อ่านเข้าใจง่าย

## โน้ตเทียบกับคำอธิบายประกอบแบบข้อความ

ใช้คำอธิบายประกอบแบบข้อความเมื่อข้อความต้องติดไปกับรูปภาพที่ส่งออก ใช้โน้ตของโปรเจกต์สำหรับข้อมูลเบื้องหลังที่ควรอยู่คู่กับงานที่แก้ไขได้

## ก่อนแชร์

เมื่อส่งออก PDF ของโปรเจกต์ ให้เลือกหนึ่งในสี่เค้าโครง:

- **รูปภาพด้านบน ข้อความด้านล่าง (Image Above, Text Below)** วางรูปภาพไว้ครึ่งบนและโน้ตไว้ด้านล่าง
- **ข้อความด้านบน รูปภาพด้านล่าง (Text Above, Image Below)** สลับลำดับดังกล่าว
- **ข้อความด้านซ้าย รูปภาพด้านขวา (Text Left, Image Right)** วางโน้ตทางซ้ายและรูปภาพทางขวา
- **รูปภาพด้านซ้าย ข้อความด้านขวา (Image Left, Text Right)** สลับตำแหน่งในเค้าโครงแนวข้าง

โน้ตจะแสดงเป็นข้อความที่จัดรูปแบบแล้ว ตรวจสอบ PDF ก่อนแชร์เพื่อให้แน่ใจว่าโน้ตและรูปภาพอ่านได้ชัดเจนในเค้าโครงที่เลือก
