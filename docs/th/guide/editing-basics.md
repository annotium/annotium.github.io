# เลือกและแก้ไขวัตถุ

## ย้ายหรือปรับรูปทรงคำอธิบาย

1. แตะ **เลื่อน (Pan)** แล้วแตะคำอธิบาย จุดจับสำหรับแก้ไขจะปรากฏขึ้น
2. ลากส่วนตัวคำอธิบายเพื่อย้ายตำแหน่ง
3. ลากจุดจับเพื่อปรับขนาดหรือรูปทรง สำหรับลูกศร จุดจับที่ปลายจะเปลี่ยนจุดเริ่มต้นหรือจุดสิ้นสุด

## เลื่อนไปรอบแคนวาส

เมื่อเปิดใช้ **เลื่อน (Pan)** ให้ลากพื้นที่ว่างบนแคนวาสเพื่อเลื่อนมุมมอง รูปภาพและคำอธิบายจะเคลื่อนที่ไปพร้อมกันบนหน้าจอ

<img src="/images/guide/pan-viewport-result.webp" alt="ผนังที่เสียหายและคำอธิบายเลื่อนไปพร้อมกันเมื่อเปิดใช้ Pan" width="360" />

## จัดการคำอธิบายที่เลือก

ใช้การดำเนินการกับรายการที่เลือกเพื่อทำสำเนาหรือลบคำอธิบาย เปลี่ยนลำดับว่าคำอธิบายใดอยู่ด้านหน้า หรือล็อกไว้เพื่อป้องกันการย้ายโดยไม่ตั้งใจ ปลดล็อกก่อนปรับรูปทรง ใช้ **เลิกทำ (Undo)** เพื่อย้อนกลับการเปลี่ยนแปลง และ **ทำซ้ำ (Redo)** เพื่อนำกลับมาใช้
