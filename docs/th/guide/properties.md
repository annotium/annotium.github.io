## เปลี่ยนสีลูกศร

1. แตะ **เลื่อน (Pan)** แล้วเลือกลูกศรบนแคนวาส
2. เปิด **คุณสมบัติ (Properties)** แล้วเลือก **เส้นขอบ (Stroke)**
3. แตะสี ลูกศรที่เลือกจะเปลี่ยนบนแคนวาส

<img src="/images/tools/arrow/arrow-properties.webp" alt="คุณสมบัติของลูกศรที่เลือกแสดงแท็บเติม (Fill), เส้นขอบ (Stroke) และเส้นทาง (Path) พร้อมจานสี" width="360" />

หากต้องการตั้งค่าสไตล์สำหรับคำอธิบายชิ้นถัดไป ให้ล้างการเลือก เลือกเครื่องมือวาด แล้วตั้งค่าคุณสมบัติก่อนวาด

## เลือกคุณสมบัติที่ต้องการ

| หากต้องการเปลี่ยน | ให้มองหา |
| --- | --- |
| สีเส้นขอบ ความทึบ ความกว้าง หรือรูปแบบเส้นประ | **เส้นขอบ (Stroke)** |
| สีหรือความทึบภายในรูปทรงปิดหรือกล่องคำบรรยาย | **เติม (Fill)** |
| ปลายลูกศรหรือตัวเลือกเรขาคณิตสำหรับเครื่องมือที่เลือก | **เส้นทาง (Path)** |
| แบบอักษร ขนาด การจัดตำแหน่ง หรือสีข้อความ | การตั้งค่าข้อความของคำอธิบายข้อความที่เลือก |

ส่วนควบคุมที่ใช้ได้ขึ้นอยู่กับเครื่องมือที่เลือก การควบคุมสไตล์บางอย่างต้องใช้พรีเมียม (Premium)
