# โปรเจกต์และรูปภาพ

แตะตัวสลับพื้นที่ทำงานที่มุมซ้ายบนของหน้าจอหลักเพื่อเลือก **โปรเจกต์ (Projects)** หรือ **รูปภาพ (Photos)** หัวข้อและกริดจะเปลี่ยนเมื่อคุณสลับ

<img src="/images/getting-started/switching.jpg" alt="ตัวสลับพื้นที่ทำงานแสดงโปรเจกต์และรูปภาพ" width="360" />

| พื้นที่ทำงาน | เลือกเมื่อ | ผลลัพธ์ที่บันทึก |
| --- | --- | --- |
| **โปรเจกต์ (Projects)** | คุณต้องการโฟลเดอร์ โน้ตโปรเจกต์ หรือกลับมาแก้ไขคำอธิบายแต่ละรายการภายหลัง | โปรเจกต์ที่แก้ไขได้ การเปิดคำอธิบายเดิมอีกครั้งต้องใช้พรีเมียม (Premium) |
| **รูปภาพ (Photos)** | คุณต้องการใส่คำอธิบายให้รูปภาพจากอัลบั้มในอุปกรณ์ | รูปภาพที่รวมคำอธิบายไว้แล้ว โดยค่าเริ่มต้นจะบันทึกไปยังคลังรูปภาพในอุปกรณ์ |
