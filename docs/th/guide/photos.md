# เรียกดูรูปภาพในอุปกรณ์

## เปิดรูปภาพ

1. สลับไปที่ **รูปภาพ (Photos)** จากหน้าจอหลัก
2. อนุญาตให้เข้าถึงรูปภาพหากอุปกรณ์ถาม หากปฏิเสธสิทธิ์การเข้าถึงแล้ว ให้แตะ **เปิดการตั้งค่า (Open Settings)** แล้วตรวจสอบสิทธิ์เข้าถึงรูปภาพของ Annotium
3. แตะชื่ออัลบั้มเพื่อเลือกอัลบั้ม แล้วแตะรูปภาพเพื่อแก้ไข

<img src="/images/photos/browse.png" alt="พื้นที่ทำงานรูปภาพแสดงชื่ออัลบั้มเหนือกริดภาพขนาดย่อ" width="360" />

ดึงกริดลงเพื่อรีเฟรช หากต้องการเริ่มด้วยรูปภาพใหม่ ให้ใช้ปุ่มกล้อง เมื่อใช้ **พรีเมียม (Premium)** ให้เปิด **+ → จัดองค์ประกอบ (Compose)** เพื่อ[รวมรูปภาพหลายรูป](/th/tools/images-compose#compose-photos)

## บันทึกรูปภาพที่ใส่คำอธิบายแล้ว

แตะ **ย้อนกลับ (Back)** แล้วเลือก **บันทึก (Save)** เมื่อมีข้อความแจ้ง รูปภาพจะบันทึกเป็นภาพที่รวมคำอธิบายไว้แล้ว โดยค่าเริ่มต้นจะบันทึกไปยังคลังรูปภาพในอุปกรณ์ หากต้องการให้แก้ไขคำอธิบายภายหลังได้ ให้เริ่มจาก[โปรเจกต์](/th/guide/projects)

## ลบรูปภาพ

แตะภาพขนาดย่อค้างไว้ แตะรูปภาพอื่นที่ต้องการเลือก แล้วเลือก **ลบ (Delete)** และตรวจสอบข้อความยืนยัน

<img src="/images/photos/delete.png" alt="พื้นที่ทำงานรูปภาพแสดงภาพขนาดย่อที่เลือกและส่วนควบคุมสำหรับจัดการรายการที่เลือก" width="360" />

::: danger คลังรูปภาพในอุปกรณ์
การลบจากที่นี่จะนำรูปภาพออกจากคลังในอุปกรณ์ของคุณ การเลิกทำของ Annotium ใช้กับการดำเนินการในตัวแก้ไข
:::
