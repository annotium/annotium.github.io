# Save, export, and share

## Understand the output types

| Output | Best for | Editable later? |
| --- | --- | --- |
| Project | Continuing work in Annotium | Yes, with the applicable access |
| JPEG or PNG | Messaging, reports, and uploads | No, flattened |
| PDF | Documents, printing, and project notes | No, delivery format |

## Save from Projects

- Project data is saved and remains editable.
- The optional **Auto save** preference for also saving an image to the gallery.
