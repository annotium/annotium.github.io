# What’s new

This page summarizes the major workflow changes represented in the current guide. It is not a substitute for store release notes.

## Annotium 4.x

- Added a project gallery for saved work.
- Added editable saved projects so annotations can be selected and revised later.
- Added project notes for supporting context.
- Added PDF export for document-oriented delivery.
- Added **Auto save to photo/gallery** as an optional output workflow.
- Added photo stitching for combining multiple images.
- Improved angle and line tools.
- Improved selection and editing for arrows, highlights, and other objects.
- Continued support for shapes, text, callouts, freehand drawing, crop, loupe,
  spotlight, privacy effects, icons, and measurement tools.

## Earlier guide coverage

The former documentation focused on browsing device photos, switching albums,
selecting photos for deletion, opening the drawing screen, and choosing from
drawing/property menus. Those concepts have been retained and reorganized
across [Projects and Photos](/guide/workspaces),
[Editor overview](/guide/editor-overview), and [Tool overview](/tools/overview).
